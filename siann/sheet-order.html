상세 창 순서 시안 (포니테일 기준)

휴대폰 폭. 각 창은 실제처럼 스크롤돼요. 위에서부터 뭐가 먼저 보이는지로 판단하세요.

A. 결정한 사람 먼저

버튼·설치법·"뭘 칠지"가 맨 위. 이미 깔기로 한 사람은 3초 만에 끝. 고민하는 사람은 내려가면서 설명→신뢰→후기→영상.

플러그인커뮤니티Claude Code

포니테일 Ponytail

AI가 쓸데없이 길게 짜는 코드를 절반으로 줄여 주는 '고참 개발자 성격'.

★★★★★ 4.6 (한국 후기 12) · 깃허브 ★ 18만 · 설치 4.1만

⚡ 딸깍 설치

설치되면 이렇게 치세요: /ponytail-review (자동으로 복사돼요)

설치 방법 (2단계)

1'딸깍 설치' 누르기 → 뜨는 창마다 '열기', '예'
2Claude 앱 왼쪽 위 </> 버튼 → 아래 입력창에 치기

이게 뭐예요?

50줄짜리 코드를 보여 주면 아무 말 없이 한 줄로 바꿔 놓는 그 고참 개발자를 AI 안에 넣은 것. 코드 -53%, 시간 -41%, 비용 -26%.

이런 분께

Claude가 코드를 너무 복잡하고 길게 짜서 돈과 시간이 아깝다고 느끼는 분

이렇게 써요

  • "/ponytail-review" 치면 바꾼 코드를 고참처럼 검토
  • 설치하면 매 세션 자동으로 켜짐
  • 과격하면 /ponytail lite, 끄려면 /ponytail off

믿어도 되나

  • 깃허브 ★18만, 개인 개발자 제작
  • MIT 라이선스
  • exe·dll 없는 순수 텍스트 (제작자 명시)
⚠ 공식 Claude 앱 목록에는 없고 제작자 저장소에서 받습니다.
