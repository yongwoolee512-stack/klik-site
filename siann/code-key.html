시안: </> 버튼 강조

"쓰는 법" 2단계 칸. 문장은 네가 준 그대로("클로드 코드에 명령 … / 평소 채팅 말고 클로드 코드 </> 버튼을 누른 화면이어야 해요"). 강조 방식만 다름.

A안 · 키캡처럼

</>를 실제 앱 버튼(검정 바탕)과 같은 모양의 작은 키캡으로. 그림 속 버튼과 글 속 버튼이 똑같이 생겨서 "아, 저거"가 바로 됨.

쓰는 법 설치 뒤 이렇게

1
클로드 코드에 명령: Claude 앱 왼쪽 위 </> 버튼 → 아래 입력창에 이렇게 치기평소 채팅 말고, 클로드 코드 </> 버튼을 누른 화면이어야 해요.
이 내용으로 10장짜리 PPT 만들어 줘
+ 그림과 1:1로 대응, 톤이 차분함
− 검정이라 네이비 포인트 색과는 안 섞임

B안 · 포인트 색 + "클로드 코드" 라벨

</>를 네이비 글자+연한 바탕으로, 앞에 "클로드 코드" 라벨 알약. 사이트 포인트 색이라 디자인에 녹아듦.

1

이 내용으로 10장짜리 PPT 만들어 줘
+ 사이트 색과 통일, "클로드 코드"가 뭔지 라벨로 한 번 더
− 그림 속 버튼(검정)과 색이 달라 연결은 A보다 약함

C안 · 네이비 키캡 + 경고줄

키캡을 네이비로(그림의 파란 테두리와 맞춤), "평소 채팅 말고" 문장은 노란 경고줄로 따로 빼서 못 놓치게.
