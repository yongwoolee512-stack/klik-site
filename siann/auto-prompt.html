시안: "설치하면 자동" 도구의 2단계

예시: 카파시 코딩 원칙 (설치만 하면 매 세션 자동 적용, 입력창에 칠 문장이 없음). 현재는 첫 팁이 복사칸에 들어가는 상태 → 아래 셋 중 고르면 그 방식으로 전부 바꿈.

A안 · 복사칸 대신 "끝" 칸

칠 게 없으면 복사 버튼을 없애고, 초록 완료 칸으로 "따로 할 거 없음"을 말한다. 단계 수·그림은 그대로.

설치 방법 (2단계)

1
'딸깍 설치' 누르기 → 뜨는 창마다 '열기', '예'

브라우저가 '딸깍 도우미를 열까요?' 하면 '열기', 도우미가 '설치할까요?' 하면 '예'. 설치 완료 창이 뜨면 끝.

2
Claude 앱 왼쪽 위 </> 버튼 → 새 대화 열기

평소 채팅 화면 말고, </> 버튼을 누른 화면이어야 해요.

✓
이 도구는 여기까지가 끝. 입력창에 따로 칠 건 없어요. 새 대화를 열면 자동으로 켜져 있어요.
+ 제일 단순. 복사할 게 없다는 걸 색으로 바로 알 수 있음
− "진짜 됐나?" 확인할 방법이 없음

B안 · "끝" 칸 + 확인용 문장(선택)

A안에 더해, 제대로 깔렸는지 보고 싶은 사람을 위해 점선 복사칸을 하나 더. "선택"이라고 명시.

설치 방법 (2단계)

1
'딸깍 설치' 누르기 → 뜨는 창마다 '열기', '예'

브라우저가 '딸깍 도우미를 열까요?' 하면 '열기', 도우미가 '설치할까요?' 하면 '예'. 설치 완료 창이 뜨면 끝.

2
Claude 앱 왼쪽 위 </> 버튼 → 새 대화 열기

평소 채팅 화면 말고, </> 버튼을 누른 화면이어야 해요.

✓
이 도구는 여기까지가 끝. 입력창에 따로 칠 건 없어요.

잘 깔렸는지 확인하고 싶으면 (선택) 입력창에 이렇게 쳐 보세요:

방금 설치한 카파시 코딩 원칙, 뭐가 바뀌는지 요약해 줘
+ 불안한 사람에게 확인 수단을 줌. 팁에 확인 문장이 있으면 그걸, 없으면 자동 생성 문장
− 칸이 하나 더 생김 (지금처럼 다닥다닥해질 수 있음)

C안 · 1단계로 줄이고 제목에 "자동 적용" 배지

칠 게 없으면 2단계 자체를 없앤다. 제목 옆에 배지, 그림은 작게 한 줄짜리 안내로.

설치 방법 (1단계) 설치하면 자동 적용

1
'딸깍 설치' 누르기 → 뜨는 창마다 '열기', '예'

브라우저가 '딸깍 도우미를 열까요?' 하면 '열기', 도우미가 '설치할까요?' 하면 '예'. 설치 완료 창이 뜨면 끝.

✓
끝. 다음에 Claude 앱 왼쪽 위 </> 버튼을 눌러 새 대화를 열면 자동으로 적용돼 있어요. 입력창에 칠 건 없음.
+ 가장 짧음. "설치 = 끝"이 한눈에
− 다른 도구는 2단계인데 이것만 1단계라 틀이 달라짐. </> 그림이 작아져서 처음 보는 사람에겐 덜 친절
