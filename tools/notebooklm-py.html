노트북LM 자동화 (팟캐스트·퀴즈·슬라이드 뽑기)

notebooklm-py

구글 NotebookLM(제미나이 노트북)에 자료를 넣고 오디오 요약, 영상, 슬라이드, 퀴즈, 플래시카드, 마인드맵을 만들어 내려받는 일을 Claude가 대신합니다. 웹 화면에 없는 일괄 다운로드도 됩니다.

이런 분께

NotebookLM을 자주 쓰는데 자료 넣고 결과 내려받는 손품이 귀찮은 분. 파이썬(uv 또는 pipx)과 구글 로그인이 필요하고, 비공식 API라 구글이 바꾸면 멈출 수 있습니다

사용 예시

  • "이 PDF 세 개로 노트북 만들고 한국어 오디오 요약 생성해서 내려받아 줘"
  • "이 노트북 자료로 어려운 난이도 퀴즈 만들어서 마크다운으로 저장해 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

구글 NotebookLM(2026년 7월 Gemini Notebook으로 이름 변경, 같은 서비스)을 파이썬·명령줄·AI 에이전트에서 다루는 비공식 라이브러리이자 스킬입니다. 웹 화면에 없는 기능(일괄 다운로드, 퀴즈·플래시카드 여러 형식 내보내기, 마인드맵 JSON 추출)까지 됩니다. 문서화되지 않은 구글 API를 쓰므로 예고 없이 깨질 수 있고 구글과 무관하며 과도한 사용은 제한될 수 있다고 경고합니다.

무엇을 할 수 있나요?

URL·PDF·유튜브·구글 드라이브를 소스로 일괄 추가, 웹/드라이브 리서치 질의와 자동 가져오기, 소스에 근거한 질문 답변, 오디오 요약(팟캐스트)·영상·슬라이드·퀴즈·플래시카드·인포그래픽·데이터 표·마인드맵·학습 가이드 생성, 결과물을 MP3/MP4/PDF/PNG/CSV/JSON/마크다운으로 내려받기, 구글 문서·시트로 내보내기. README는 NotebookLM이 무거운 읽기와 인용 달린 답을 맡고 Claude가 그 결과를 이어 가공하는 패턴을 권합니다.

쓰는 법

uv tool install "notebooklm-py[browser]" (또는 pipx)로 설치하고 notebooklm login 을 하면 크로미움(약 170MB)을 받고 구글 로그인 창이 뜹니다. 이미 로그인된 크롬의 쿠키를 재사용하는 옵션(--browser-cookies chrome)도 있습니다. 이후 notebooklm create, source add, ask, generate audio --wait, download audio 같은 명령을 쓰거나 Claude에게 맡기면 됩니다. 저장소 루트의 SKILL.md가 스킬입니다.

주의할 점

비공식 API라 구글이 내부 엔드포인트를 바꾸면 작동이 멈출 수 있고, 시제품·연구·개인 용도에 적합하다고 스스로 밝힙니다. 구글 계정 인증 정보가 로컬 프로필에 저장되므로 공용 컴퓨터에서는 피하세요.
