Prisma로 데이터베이스를 다루는 개발자. 코드와 DB 지식이 필요한 개발자용 도구입니다

  • "prisma-upgrade-v7로 이 프로젝트를 Prisma 7로 올려 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

데이터베이스 ORM인 Prisma와 Prisma Postgres, 앱 배포 서비스 Prisma Compute를 위한 공식 스킬 모음입니다. Claude가 Prisma 명령과 API를 정확하게 쓰게 하는 포장된 설명서입니다.

안에 뭐가 있나요?

prisma-cli(ORM 7 명령: init, migrate, db push, studio 등), prisma-upgrade-v7(v6→v7 변경점 단계별 안내), prisma-mongodb-upgrade(MongoDB 프로젝트의 선택지), prisma-client-api(쿼리·트랜잭션·raw SQL 참고서), prisma-driver-adapter-implementation(어댑터 개발), prisma-orm-setup(Prisma 8 설정과 기존 버전 유지), prisma-postgres-setup(DB가 없을 때 만들고 연결), prisma-compute(배포, 로그, 롤백, 환경변수, 도메인).

쓰는 법

설치 뒤 "Prisma 7로 업그레이드해 줘", "DB 필요해" 같은 요청을 하면 맞는 스킬이 자동으로 쓰입니다. Vercel에 배포하는 프로젝트에선 Vercel 플러그인 설치를 제안하되 사용자 동의를 받고 설치합니다.

주의할 점

데이터베이스 마이그레이션은 데이터에 영향을 줄 수 있으니 백업 후 진행하세요. 개발자용 도구입니다.
