깃허브 원문 설명 한글판

이게 뭐예요?

캔바(Canva)가 직접 만든 공식 플러그인입니다. 캔바 MCP 서버를 통해 디자인을 새로 만들고, 기존 디자인을 고치고, 다른 크기로 바꾸고, 브랜드 규칙(색·글꼴·로고)에 맞는지 검사합니다.

설치와 첫 사용

딸깍 설치 뒤 처음 쓸 때 캔바 로그인 창이 한 번 뜹니다. 승인하면 끝. 그다음 "인스타 카드뉴스 5장 만들어 줘"처럼 말하면 캔바에 디자인이 생기고 링크를 돌려줍니다.

주의

무료 캔바 계정도 되지만, 브랜드 키트 검사 같은 일부 기능은 캔바 프로가 필요합니다.
