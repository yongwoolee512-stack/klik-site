내 GitHub 프로젝트의 README를 프로젝트 가치·실제 사례·설치법·한계가 한눈에 읽히도록 정리하고, 프로젝트 성격에서 끌어낸 대표 이미지(SVG 등)까지 디자인해 줍니다.

사용 예시

  • "이 저장소 README를 beautify-github-readme로 다시 써 줘, 한국어로"
  • "README 상단에 프로젝트 성격이 드러나는 대표 이미지 만들어 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

저장소 README를 정리하고 디자인해서 프로젝트의 가치, 실제 사례, 설치 방법, 사용 범위가 더 쉽게 이해되도록 하는 Claude Code·Codex용 스킬입니다. 영어·중국어·일본어 README가 있고 스킬은 skills/beautify-github-readme/SKILL.md에 있습니다.

적용 사례

README에 적용 사례 8개가 실려 있습니다. oil-ppt(프로그램으로 슬라이드 만드는 방법·결과·첫 사용 경로를 한 시각 체계로), draw-ui(브리프와 참고 이미지에서 HTML/CSS 재구성까지의 경로를 실제 UI 결과로 설명), oil-icon(아이콘 세트의 스타일 고정·일괄 생성·슬라이스·투명 납품), Selector, codex-dev-team(캐릭터 기반 팀 지도), torqueDASH-Next(차량 OBD-II 데이터로 만든 SVG 히어로), summertown(해변 지도 히어로), Wolfcha(SVG 타이포와 AI 생성 캐릭터 컷아웃). 이 스킬로 만든 공개 README가 자랑스럽다면 PR로 사례 추가를 제안할 수 있고 푸터 서명은 선택입니다.

대표 이미지 방향

서로 다른 네 가지 히어로 방향을 보여 주는데 하나의 집 스타일을 공유하지 않고 각각 프로젝트 자체에서 타이포·색·구성·증거를 끌어냅니다. 예를 들어 Block World는 SVG로 픽셀 타이포·그리드·장면을 만들고, 결정적으로 그리기 번거로운 캐릭터는 이미지 생성과 크로마키 제거로 보충하는 혼합 방식입니다.

주의할 점

GitHub 저장소를 운영하는 개발자용입니다. 캐릭터 이미지 같은 일부 사례는 이미지 생성 도구를 함께 썼습니다.
