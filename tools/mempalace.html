멤팰리스 (대화 기억 보관소)

MemPalace

Claude와 나눈 대화를 요약하지 않고 원문 그대로 내 컴퓨터에 쌓아 두고, 나중에 "그때 왜 그렇게 정했지?" 하면 찾아서 꺼내 줍니다.

GitHub ★ 60,183skills.sh 설치 2,018회
딸깍에서 한 번에 설치하기

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

세션이 바뀌면 Claude가 지난 대화를 잊어버려 답답한 분. 파이썬(3.10 이상)이 필요하고 처음에 모델 파일(약 300MB)을 받습니다

사용 예시

  • "멤팰리스 설치하고 내 Claude Code 대화 기록을 긁어 넣어 줘"
  • "지난달에 블로그 톤 어떻게 정했는지 기억 보관소에서 찾아 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

내 컴퓨터에만 저장되는 AI 기억 저장소입니다. 대화 기록을 요약하거나 바꿔 쓰지 않고 원문 그대로 보관한 뒤 의미 검색으로 꺼내 옵니다. 사람·프로젝트는 '윙', 주제는 '룸', 원문은 '서랍'이라는 구조로 정리해 범위를 좁혀 찾을 수 있습니다. 기본 저장 엔진은 ChromaDB이고 바꿀 수 있습니다.

안에 뭐가 있나요?

스킬 세 개가 핵심입니다. mempalace(설치·운영 안내), mempalace-recall(답하기 전에 먼저 기억을 검색), mempalace-task(작업 위임용 로그). 스킬을 설치해도 MemPalace 프로그램 자체가 깔리는 건 아니고, 설치 스킬이 Claude를 통해 파이썬 패키지와 MCP 설정을 안내합니다. 저장소에는 SKILL.md가 15개 있습니다.

쓰는 법

스킬을 설치한 뒤 Claude에게 'MemPalace 설정해 줘'라고 하면 시스템을 확인하고 개인용/공유용 중 묻고 설치합니다. 직접 하려면 uv tool install mempalace 또는 pipx install mempalace 후 mempalace init 폴더경로. 파이썬 3.10 이상, 임베딩 모델 파일 약 300MB(영어 전용 소형은 30MB)가 필요합니다. 도커 이미지도 있습니다.

주의할 점

README가 사칭 사이트를 강하게 경고합니다. 공식은 GitHub 저장소, PyPI, mempalaceofficial.com 세 곳뿐이고 다른 도메인은 악성일 수 있습니다. Claude Code 세션은 자동 저장 훅을 걸지 않으면 30일 뒤 만료된다고 안내합니다. 주간 업데이트 확인은 기본 꺼짐이며 켜도 PyPI만 조회하고 자동 설치는 하지 않습니다.
