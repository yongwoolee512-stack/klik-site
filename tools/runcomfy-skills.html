원문 설명 한글판

이게 뭔가요?

RunComfy라는 AI 미디어 플랫폼의 모델들을 Claude에서 바로 쓰게 해 주는 스킬 모음입니다. README 자체는 '한 번에 하나씩 올려 skills.sh 색인을 확인하고 있다'는 짧은 안내뿐이고, 실제 설명은 각 스킬 폴더의 SKILL.md에 있습니다.

안에 뭐가 있나요?

runcomfy-cli(모든 스킬의 바탕. 설치·로그인·모델 실행 방법), ai-image-generation, ai-video-generation, image-to-video, video-edit(의도에 맞춰 Wan 2.7·Kling·Lucy Edit 중 모델을 골라 줌), image-edit, lipsync, face-swap, image-inpainting/outpainting, video-extend, controlnet-pose, relight, nano-banana-2, gpt-image-2, kling-3-0, seedance-v2, wan-2-7 등 30개 안팎의 모델별·용도별 스킬이 있습니다.

쓰는 법

npm i -g @runcomfy/cli 로 CLI를 설치하고 runcomfy login 으로 브라우저 로그인한 뒤, "이 사진을 5초 영상으로 만들어 줘"처럼 말하면 스킬이 적절한 모델을 골라 runcomfy run 명령을 실행하고 결과 파일을 내려받습니다.

주의할 점

모델 실행은 초 단위로 과금됩니다. 설치 스크립트를 셸에 바로 흘려 넣지 말고 npm으로 설치하라고 스킬 자체가 권고합니다. 같은 내용의 저장소가 gencraft-labs/skills 이름으로도 있습니다.
