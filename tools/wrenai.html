설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

Postgres 등 실제 데이터베이스를 가진 데이터 담당자·개발자용. 파이썬으로 wrenai CLI를 설치하고 DB 연결을 해야 하므로 비개발자 혼자 쓰기는 어렵습니다

사용 예시

  • "Wren으로 내 Postgres 데이터베이스 연결 설정해 줘"
  • "이번 달 지역별 주문 건수를 필터 가능한 대시보드로 만들어 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

오픈소스 생성형 BI(GenBI) 엔진입니다. 내가 이미 쓰는 에이전트(Claude Code, Cursor, MCP 클라이언트 등)에 '통제된 시맨틱 레이어'와 'AI 컨텍스트 레이어'를 붙여, 업무 질문을 정확한 SQL로 바꾸고 결과를 공유 가능한 대시보드로 배포하게 합니다. 스키마가 데이터 위치를 알려 준다면 Wren은 데이터의 의미(승인된 지표 정의, 코드값, 단위, 조인, 예시, 문서·채팅에 묻힌 노하우)를 알려 주며, 전부 내 저장소의 YAML·마크다운 파일로 검토 가능하게 보관됩니다. 22개 이상 데이터 소스를 지원합니다.

쓰는 법

세 단계입니다. pip install wrenai 로 CLI 설치(postgres 등 커넥터는 추가 옵션), npx skills add Canner/WrenAI 로 약 50줄짜리 안내 스킬 설치(상세 지침은 설치된 CLI 버전에서 가져오므로 항상 버전이 맞음), 프로젝트 폴더에서 'Wren으로 내 Postgres 설정해 줘'라고 요청. DB가 없으면 내장 샘플 jaffle_shop으로 같은 흐름을 체험할 수 있습니다.

이후 흐름

Know: 'raw/ 폴더의 업무 맥락으로 Wren 프로젝트 보강해 줘' → 정의·예시·메모리를 파일로 기록. Generate: '이번 분기 매출 상위 10 고객은?' → 맥락과 과거 질의를 떠올려 통제된 SQL을 쓰고 실행. Deploy: '필터 가능한 대시보드로 Vercel에 배포해 줘' → 브라우저용 앱을 만들어 내 Vercel 또는 Cloudflare Pages 계정에 올리고 URL을 돌려줍니다.

주의할 점

실제 데이터베이스 연결과 파이썬 환경이 전제라 데이터 담당자·개발자용입니다. 스키마 인식 검색, 사전 계획 검증, 행 수 제한 같은 가드레일로 '자신 있게 틀리는' SQL을 막는 것이 핵심 가치라고 설명합니다.
