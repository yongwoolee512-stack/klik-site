  • "AWS 아이콘으로 서버 구성도 그려 줘"
  • 그려진 그림은 .drawio·.png·.svg로 저장되고 Ctrl+Z로 되돌릴 수 있어요.

깃허브 원문 설명 한글판

이게 뭐예요?

한 문장으로 설명하면 AI가 진짜 draw.io 캔버스에 도표를 그려 주는 프로젝트입니다. 웹앱, Windows·macOS·Linux 데스크톱 앱, 그리고 Claude Code 같은 AI 에이전트용 MCP 서버 세 가지 모양으로 제공됩니다. 아키텍처 도식, 순서도, 시퀀스 다이어그램을 만들 수 있고 AWS·Azure·GCP·Kubernetes 아이콘이 내장돼 있습니다.

고치기

채팅으로 고치면 바뀐 도형이 캔버스에 강조 표시됩니다. 도형 몇 개를 선택하고 "이것만 바꿔 줘"라고 하면 그 부분만 바뀝니다. AI가 바꾼 내용은 매번 버전 카드로 남아 비교·복원할 수 있고, 캔버스에서 Ctrl+Z 한 번으로 AI의 변경을 되돌릴 수 있습니다. 스크린샷이나 손그림을 올리면 다시 그려 주기도 합니다.

MCP로 쓰면

Claude Code에서는 `claude mcp add --scope user drawio -- npx @next-ai-drawio/mcp-server@latest` 한 줄로 등록합니다(커뮤니티 마켓플레이스 플러그인도 있음). 웹앱의 그리기 기능 대부분이 들어 있고, AI가 그려진 그림을 스크린샷으로 확인해 고치는 도구, 버전 기록, 여러 페이지, .drawio·.png·.svg 내보내기, ~/.next-ai-drawio/ 자동 저장을 지원합니다. draw.io 편집기가 패키지 안에 들어 있어 미리보기는 오프라인에서도 됩니다.

알아 둘 것

웹 데모는 사용량 제한이 있고 직접 API 키를 넣으면 풀립니다. MCP 서버는 Claude Code가 그리는 쪽이라 따로 키가 필요하지 않습니다. 라이선스는 Apache 2.0입니다.
