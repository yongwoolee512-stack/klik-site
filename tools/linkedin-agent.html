깃허브 원문 설명 한글판

이게 뭐예요?

링크드인 계정을 운영하는 Claude 스킬 11개입니다. 무료·MIT, 연결할 계정이나 API 키가 없습니다. 글은 스킬이 쓰고 올리는 건 사람이 합니다. 승인 없이는 아무것도 게시되지 않습니다.

주요 기능

/li-post(21가지 훅 공식으로 글), /li-comment(댓글), /li-reply(내 글 아래 답글 분류·작성), /li-profile(프로필 100점 채점·수정), /li-plan(주간 계획), /li-human(AI 티 제거·검사), /li-carousel, /li-repurpose, /li-dm, /li-inbox 등.

설치와 사용

플러그인 설치 뒤 templates/voice.md 를 ~/.claude/linkedin/voice.md 로 복사해 내 말투를 채워 두세요. 모든 스킬이 이 파일을 읽습니다. 건너뛰면 남들과 비슷한 글이 나온다고 README가 경고합니다.

주의

humanizer의 파이썬 도구 2개가 핵심이라 Claude Code 밖에서는 효과가 줄어듭니다.
