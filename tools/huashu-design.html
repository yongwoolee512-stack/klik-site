Huashu Design

"관찰 기록 앱 시안 만들어 줘" 한 줄로 클릭되는 앱 시안, 편집 가능한 PPTX, 짧은 MP4 애니메이션, 인포그래픽을 뽑습니다. 방향이 막연하면 후보 6장을 먼저 보여 주고 3개를 골라 완성합니다.

이런 분께

디자이너 없이 제품 시안·발표 자료·소개 영상을 뽑아 보고 싶은 분. 로고·색상 등 브랜드 자료를 주면 결과가 훨씬 좋아진다고 제작자가 말합니다

사용 예시

  • "우리 카페 메뉴판 앱 시안 세 방향으로 보여 주고 고르게 해 줘"
  • "이 발표 원고를 편집 가능한 PPTX로 만들어 줘, 한국어로"

깃허브 원문 설명 한글판

이게 뭔가요?

'타이핑하고 엔터 치면 납품 가능한 디자인이 나온다'를 내세우는 디자인 스킬입니다. 3~30분 안에 제품 발표 애니메이션, 클릭되는 앱 시안, 편집 가능한 PPTX, 인쇄 품질 인포그래픽을 만든다고 합니다. 로고·색상·UI 스크린샷 같은 브랜드 자산을 주면 그 분위기를 읽고, 아무것도 없으면 후보 6장 중 3개 방향과 92종 스타일 라이브러리로 'AI 티'를 피합니다. 2026-05-14부터 MIT로 상업 사용도 무료입니다.

무엇을 만들 수 있나요?

앱/웹 인터랙티브 시안(iPhone 베젤, 클릭 가능, Playwright로 검증, 10~15분), 발표 슬라이드(브라우저용 HTML 덱 + 텍스트 상자가 살아 있는 PPTX, 15~25분), 타임라인 애니메이션(MP4·GIF·배경음악, 8~12분), 디자인 변형 3개 이상 나란히 비교, 인포그래픽(PDF/PNG/SVG), 샤오홍슈용 3:4 세트 이미지, 디자인 방향 자문, 5개 축 전문가 평가(레이더 차트와 고칠 목록).

쓰는 법

npx skills add alchaincyf/huashu-design 으로 설치하고 Claude Code에서 한 문장으로 요청합니다. 설치 후 폴더에 references/, assets/, scripts/, demos/ 네 하위 폴더가 있는지 꼭 확인하라고 합니다. SKILL.md만 있으면 skills CLI가 오래된 것이니 npm i -g skills@latest 후 다시 설치하거나 git clone으로 받으라고 안내합니다.

주의할 점

핵심 흐름(디자인→렌더→MP4/PDF/PPTX)은 100% 로컬이고 네트워크·키가 필요 없습니다. 더우바오 TTS 음성, AI 영상 평가 같은 클라우드 기능은 scripts/cloud/에 격리된 선택 사항으로 본인 키를 쓰고 첫 호출 때 --yes 확인이 필요합니다. 한계로 PPTX를 Figma로 레이어 편집 불가, Framer Motion급 복잡 애니메이션(3D·물리·파티클) 불가, 브랜드 자료가 전혀 없으면 품질이 60~65점으로 떨어진다고 스스로 밝힙니다.
