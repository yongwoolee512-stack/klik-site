과학 연구 스킬 177종 (K-Dense)

Scientific Agent Skills

이런 분께

논문·실험 데이터를 다루는 연구자·대학원생용. 파이썬과 각 과학 패키지 설치가 전제라 일반 사용자에겐 무겁습니다. 스킬이 177개라 설치하면 스킬 목록이 아주 길어집니다

사용 예시

  • "이 RNA-seq 결과 파일 품질 확인하고 유전자별 카운트 표로 정리해 줘"
  • "PubMed에서 이 주제 최근 논문 찾아서 표로 요약해 줘"
  • 177개 중 자주 쓰일 것: Database Lookup(과학 DB 80종 검색), Biopython, RDKit(화학 구조), Scanpy(단일세포), scikit-learn

깃허브 원문 설명 한글판

이게 뭔가요?

K-Dense가 만든 과학·연구용 스킬 177개 모음입니다. 생물정보학, 화학, 의학, 물리, 공학, 지구과학, 데이터 분석, 과학 커뮤니케이션을 다루며 각 스킬이 특정 패키지·데이터 소스·워크플로의 사용법과 과학적 관례, 검증 방법을 담고 있습니다. 예전 이름은 Claude Scientific Skills였고 지금은 Agent Skills 표준을 따르는 모든 에이전트에서 씁니다. arXiv 논문(2609.00065)으로도 정리됐습니다.

안에 뭐가 있나요?

과학 데이터베이스 100개 이상(Database Lookup 스킬 하나가 80개 DB를 안내), 파이썬 패키지 스킬 70개 이상(RDKit, Scanpy, scikit-learn, Biopython, GeoPandas, Qiskit, OpenMM 등). 생물정보학·유전체학만 32개입니다. 카테고리가 겹쳐서 분야별 수를 더하면 177보다 큽니다. 스킬에 없는 패키지도 Claude가 직접 설치해 쓸 수 있고, 스킬은 자주 쓰는 길을 빠르고 안정적으로 만들어 주는 역할입니다.

쓰는 법

npx skills add K-Dense-AI/scientific-agent-skills 또는 GitHub CLI의 gh skill install 로 설치하며, 특정 스킬만(예: scanpy) 골라 설치할 수도 있습니다. 설치 후 연구 작업을 말로 요청하면 됩니다. 같은 회사가 만든 무료 데스크톱 앱 K-Dense BYOK(본인 API 키 사용)는 이 스킬들을 내장한 연구 작업 공간입니다.

주의할 점

177개 전부를 설치하면 스킬 목록이 매우 길어지니 필요한 분야만 고르는 게 낫습니다. 각 스킬의 의존 패키지와 실행 환경은 해당 SKILL.md를 따라야 하고, 예제는 '검토된 출발점'이지 대상 환경에서 직접 검증하라고 안내합니다. 연구자용이라 일반 사용자에게는 무겁습니다.
