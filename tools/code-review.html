깃허브 원문 설명 한글판

이 저장소는?

Anthropic이 운영하는 Claude Code 공식 플러그인 디렉터리입니다. 설치 전 플러그인을 신뢰할 수 있는지 확인하라는 경고가 맨 위에 있습니다.

code-review가 하는 일

지금 바꾼 코드를 여러 관점(버그, 보안, 성능, 중복)으로 나눠 검토하고, 발견한 문제를 심각도 순으로 정리해 줍니다. 혼자 개발해서 봐 줄 동료가 없을 때 두 번째 눈 역할을 합니다.

써 보기

Claude Code에서 /code-review 한 줄이면 됩니다. 깃허브 PR 번호를 주면 그 PR을 검토합니다.
