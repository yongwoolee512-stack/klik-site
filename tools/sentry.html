이게 뭐예요?

센트리 MCP는 내 서비스에서 난 오류를 AI가 읽고, 원인을 찾고, 고치게 해 주는 연결입니다. 센트리는 '일반용'이 아니라 개발자의 디버깅 흐름에 맞춰 도구를 골랐다고 밝힙니다.

시작하기

원격 서비스 mcp.sentry.dev 에 모든 안내가 있습니다. Claude Code 플러그인(sentry-mcp)으로 설치하면 센트리 오류·추적·성능 질문을 자동으로 전담 에이전트가 처리합니다. 딸깍은 원격 MCP 주소(mcp.sentry.dev/mcp)를 등록합니다.

주의 (원문)

자연어 검색 도구(search_errors 등)는 LLM 제공자 설정이 필요합니다. 직접 설치형(stdio)은 아직 작업 중이며 자체 호스팅 센트리용입니다.
