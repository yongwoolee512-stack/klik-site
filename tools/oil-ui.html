깃허브 원문 설명 한글판

이게 뭔가요?

AI 에이전트용 인터페이스 디자인 스킬입니다. 방향 하나를 추천해 실제 스크린샷을 보며 다듬거나, 비교를 요청하면 여러 방향을 나란히 탐색합니다. 웹사이트, 앱, 대시보드, 컴포넌트에 쓰고 ui.oiloil.org에서 더 많은 디자인을 볼 수 있습니다. 영어·중국어 README가 있습니다.

어떻게 디자인하나요?

1) 제품이 무엇인지 먼저 파악하고 스타일이 뚜렷한 동종 서비스 2~3개를 살펴 무엇을 지키고 바꿀지 결정. 2) '프리미엄', '깔끔'을 실제 결정(어떤 글꼴, 여백은 얼마나, 색은 어디까지)으로 번역. 3) 각 방향을 소재·장면·캐릭터·다른 분야의 시각 언어 같은 구체적인 것에서 출발. 4) 첫 화면이 누구를 위한 건지 결정(둘러보기·구매·업무 페이지는 콘텐츠가 먼저, 설득 페이지만 디자인된 오프닝). 5) 비교를 요청하면 레이아웃·타이포·색·핵심 이미지 중 두 안 사이에 겹치는 건 최대 하나로 제한하고 비슷하면 레이아웃을 바꿈. 6) 기억에 남는 순간 한두 개(탭 반응, 결제 성공, 404)만 특별하게. 7) 최종 선택은 내가.

쓰는 법

npx skills add oil-oil/oil-ui 로 설치하면 설정 없이 바로 씁니다. 새 버전이 나오면 에이전트가 답 끝에 알려 주고 원할 때 업데이트합니다. 예: 'oil-ui로 이 강의 예약 제품의 디자인 방향 몇 개를 탐색하고 미리볼 페이지 만들어 줘', '타이포·색·구성이 다른 디자인 세 개를 비교 페이지에 올려 줘', '프로젝트 디자인 가이드로 이 페이지 다듬어 줘', '이 홈페이지 검토해서 바꿀 점 설명해 줘'.

주의할 점

유료 Oil UI Pro가 따로 있으며 이미 있다면 오픈소스판은 필요 없고, 둘을 함께 설치하면 같은 요청을 두고 경쟁합니다. DeepSeek Harness 사용자는 네이티브 플러그인 dsh-oil-ui를 안내합니다.
