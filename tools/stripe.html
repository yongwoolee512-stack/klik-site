이 저장소는?

스트라이프의 AI 연동 모음입니다. 결제·구독 인프라를 AI 앱에 붙이는 SDK와, AI 에이전트용 스킬·플러그인이 들어 있습니다.

MCP

스트라이프가 원격 MCP 서버(mcp.stripe.com)를 직접 운영합니다. 로그인(OAuth)으로 안전하게 연결됩니다.

Claude Code 설치 (원문 권장)

스트라이프는 Anthropic 공식 마켓의 stripe 플러그인 설치를 권장합니다(claude plugin install stripe@claude-plugins-official). 플러그인에는 MCP 연결과 스트라이프 최신 모범 사례 스킬이 함께 들어 있고 자동 갱신됩니다. 딸깍 설치가 이 명령을 대신합니다.

한국 사용자 주의 (딸깍 편집팀)

스트라이프는 국내 사업자 가입이 제한적입니다. 국내 결제는 토스페이먼츠 등 별도 확인이 필요합니다.
