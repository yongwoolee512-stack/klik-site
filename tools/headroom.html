이게 뭐예요

AI에 보내기 전에 도구 결과, 로그, 파일, 검색 결과를 압축해 주는 도구입니다. 예시로 로그 10,144토큰이 1,260토큰으로 줄어도 같은 오류를 똑같이 찾아냅니다. 압축은 내 컴퓨터에서만 일어나고 내용은 어디로도 보내지 않습니다.

쓰는 방식 네 가지

(1) 프로그램 안에서 compress() 함수로, (2) 프록시 서버로(코드 수정 없이), (3) headroom wrap claude 처럼 Claude Code·Codex·Cursor 등을 한 줄로 감싸서, (4) MCP 서버로. 비개발자에게 현실적인 건 (3)입니다.

어떻게 줄이나

내용 종류를 알아내서 JSON은 SmartCrusher, 소스코드는 CodeCompressor, 일반 글은 Kompress 모델이 각각 압축합니다. 원본은 내 컴퓨터에 보관돼서(CCR) 모델이 필요하면 headroom_retrieve 로 전체를 다시 꺼내 봅니다. 모델이 '쓰는' 답도 군더더기를 줄입니다.

추가 기능

Claude·Codex·Gemini·Grok 사이에 기억을 공유하는 메모리, 실패한 세션에서 교훈을 뽑아 CLAUDE.md에 적어 주는 headroom learn 기능이 있습니다.

설치

pip install "headroom-ai[all]" (파이썬 3.10 이상). 그다음 headroom wrap claude 로 Claude Code를 감싸서 실행합니다. 되돌리려면 headroom unwrap claude.
