깃허브 원문 설명 한글판

문제: 컨텍스트의 '나머지 절반'

MCP 도구를 부를 때마다 날 데이터가 대화창(컨텍스트)에 쏟아집니다. Playwright 스냅샷 56KB, 깃허브 이슈 20개 59KB, 접근 로그 하나 45KB. 30분 뒤면 컨텍스트의 40%가 사라집니다. 그리고 에이전트가 공간을 비우려고 대화를 압축하면, 편집 중인 파일·진행 중 과제·마지막 요청을 잊어버립니다. 거기에 인사·군말·장황한 설명으로 출력 토큰까지 태웁니다.

해결: 네 가지

1) 컨텍스트 절약: 샌드박스 도구가 날 데이터를 컨텍스트 밖에 둡니다. 315KB가 5.4KB로, 98% 감소.
2) 세션 연속성: 모든 파일 편집·git 작업·과제·오류·사용자 결정을 SQLite에 기록. 압축이 일어나면 그걸 다 다시 쏟는 게 아니라 전문 검색(FTS5·BM25)으로 '관련 있는 것만' 꺼냅니다. --continue 를 안 쓰면 이전 세션 데이터는 즉시 지워집니다.
3) 코드로 생각하기: 파일 50개를 읽어 함수를 세는 대신, 세는 스크립트를 써서 결과만 출력합니다(47번 Read 700KB → 1번 실행 3.6KB).
4) 말투 강제 없음: 데이터가 '어디로 가는지'만 다루고, 답을 어떻게 쓰는지는 모델(또는 내 CLAUDE.md)에 맡깁니다. 과한 간결 지시는 코딩·추론 성능을 떨어뜨린다는 보고가 있어서입니다.

설치

Claude Code 1.0.33 이상. /plugin marketplace add mksglu/context-mode → /plugin install context-mode@context-mode. 딸깍이 이 두 줄을 대신합니다. 플러그인 없이 MCP만 붙이려면 claude mcp add context-mode -- npx -y context-mode.

Node.js(npx)로 돌아가는 MCP 서버입니다. Node.js가 없는 컴퓨터에서는 설치돼도 켜지지 않을 수 있습니다. ctx stats 로 도구가 켜졌는지 확인합니다.

지원 범위

Claude Code, Gemini CLI, VS Code·JetBrains Copilot, OpenCode, KiloCode에서 세션 연속성(기록+스냅샷+복원)이 완전히 동작합니다. Codex CLI는 부분 지원, Cursor는 압축 후 복원이 아직 안 됩니다. Copilot CLI, Antigravity CLI, OMP, OpenClaw 게이트웨이 등 17개 클라이언트용 설정이 들어 있습니다. 라이선스는 ELv2(쓰는 건 자유, 서비스로 되파는 것만 제한). 디스코드 커뮤니티가 있습니다.
