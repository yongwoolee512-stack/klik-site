원문 설명 한글판

이게 뭐예요?

피그마 MCP 서버는 피그마 디자인 파일의 정보(색, 글꼴, 간격, 구성요소)를 AI에게 직접 넘겨 주는 연결 통로입니다. 디자인 시안을 보고 코드를 짜거나, 반대로 코드에서 피그마 시안을 만들 수 있습니다.

주요 기능

• 선택한 프레임을 코드로 변환
• 디자인 변수·구성요소·레이아웃 정보 가져오기
• (원격 서버) AI가 피그마 캔버스에 직접 그리기: 프레임·구성요소·자동 레이아웃 생성·수정
• 이미지가 없을 때 자리 채움 이미지 생성 (피그마 AI 크레딧 사용, 사전 동의 필요)
• 웹페이지를 피그마 디자인으로 가져오기 (순차 배포 중)

요금·제한 (중요)

스타터 요금제이거나 유료 플랜의 View/Collab 좌석이면 월 6회만 쓸 수 있습니다. Dev 또는 Full 좌석(Professional 이상)은 분당 제한만 있습니다. 캔버스에 그리기 기능은 베타 동안 무료지만 나중에 사용량 과금으로 바뀔 예정입니다.

Claude Code 설치 (원문 권장 방식)

피그마가 권장하는 방식은 Anthropic 공식 마켓의 figma 플러그인 설치입니다. 딸깍 설치가 바로 그 명령(claude plugin install figma@claude-plugins-official)을 대신 눌러 줍니다. 설치 후 피그마 로그인 창이 한 번 뜹니다.

피그마 링크를 붙여 넣고 "이 화면 그대로 코드로 만들어 줘"라고 하면 됩니다.
