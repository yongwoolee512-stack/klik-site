원문 설명 한글판

이게 뭐예요?

리니어(Linear)는 개발팀이 많이 쓰는 이슈 관리 도구입니다. 이 플러그인은 리니어 공식 MCP 서버를 Claude에 붙여 이슈 생성·상태 변경·프로젝트 검색을 채팅으로 합니다. Anthropic이 공식 마켓에 직접 올렸습니다.

설치와 첫 사용

딸깍 설치 뒤 처음 쓸 때 리니어 로그인 승인 한 번. 그다음 "이번 스프린트 남은 이슈" 같은 질문이나 "이 버그 이슈로 만들어" 같은 명령이 됩니다. 코드 고치면서 이슈 상태를 같이 바꿔 주기도 합니다.
