이게 뭔가요?

Databricks 산하 Neon이 제공하는 에이전트 스킬 모음입니다. Neon은 Lakebase Postgres를 중심으로 인증, 실시간, 파일 저장, 함수, Data API, AI 게이트웨이를 묶은 클라우드 백엔드이며, 이 스킬들은 Claude가 그것들을 정확히 쓰도록 하는 설명서입니다.

안에 뭐가 있나요?

neon(전체 개요와 시작법, 계정 없이 쓰는 Claimable Neon 포함), neon-postgres(Postgres 문서와 모범 사례 색인), neon-auth(Managed Better Auth 로그인·세션), neon-postgres-branches(마이그레이션 테스트용 브랜치 선택), neon-postgres-egress-optimizer(과도한 데이터 전송 비용 진단), neon-object-storage(S3 호환 저장소), neon-ai-gateway(여러 LLM을 하나의 API로), neon-functions(서버리스 Node.js 함수), 그리고 에이전트 플랫폼용 스킬.

쓰는 법

설치하면 관련 작업을 감지해 자동으로 쓰입니다. "Neon에 데이터베이스 만들어서 연결해 줘", "브랜치 만들어서 마이그레이션 테스트해 줘" 같은 요청에 반응합니다.

주의할 점

클라우드 자원을 만들면 비용이 생길 수 있습니다. 개발자용입니다.
