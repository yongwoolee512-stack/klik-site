깃허브 원문 설명 한글판

이게 뭔가요?

나와 AI 에이전트가 함께 쓰도록 설계된 브라우저입니다. 에이전트는 같은 브라우저 안의 격리된 작업 공간 '스페이스'에서 일하고 나는 내 탭에서 계속 브라우징하므로 브라우저를 빼앗기지 않습니다. browser-use나 agent-browser처럼 별도 브라우저를 다리로 연결하는 방식과 달리 하나의 브라우저라 로그인·탭을 그대로 쓰고 연결이 안정적이라고 설명합니다. macOS와 Windows를 지원하며 리눅스는 로드맵에 있습니다.

쓰는 법

앱을 내려받아 설치하면 ego-browser 스킬이 내 컴퓨터의 모든 에이전트 스킬 폴더에 추가됩니다. 또는 npx skills add citrolabs/ego-lite 로 스킬만 먼저 설치하면 첫 브라우저 작업 때 앱 설치를 안내합니다. 첫 실행 시 크롬 데이터를 가져올지 한 번 묻는데, 수락하면 로그인·쿠키·확장·북마크를 에이전트가 이어받습니다. 이후 '/ego-browser x.com에서 @계정 팔로우해 줘'처럼 말하면 에이전트가 자기 스페이스에서 페이지를 열고 스냅샷(구조화된 텍스트)을 읽어 작업합니다.

특징

기능을 CLI 명령이 아니라 자바스크립트 함수로 노출해 에이전트가 여러 단계를 코드 한 번에 묶어 실행하므로 토큰과 호출 횟수가 적다고 합니다. 스페이스마다 다른 에이전트·작업을 동시에 돌릴 수 있고(예: Claude Code가 10개 스페이스에서 리드 10건 보강), 어느 스페이스에 에이전트가 돌고 있는지 보고 언제든 넘겨받거나 멈출 수 있습니다. 중첩 iframe 같은 어려운 페이지도 스냅샷 품질이 높다고 주장합니다.

주의할 점

브라우징 데이터·쿠키는 기기에 남고, 수집은 '기본 브라우저로 설정했는지' 같은 단순 제품 신호로 좁게 유지한다고 README가 밝힙니다. 내 로그인 상태를 에이전트가 쓰는 구조이므로 어떤 작업을 맡길지는 신중히 정하세요.
