이런 분께

AI가 만든 웹 화면이 다 비슷비슷하게 느껴지는 사람. 웹 프로젝트 폴더에서 씁니다

사용 예시

  • "/impeccable critique 가격표 카드"
  • "/impeccable polish 설정 화면"

skills.sh 원문 설명 한글판

이게 뭔가요?

코딩 에이전트를 위한 '디자인 어휘'입니다. "멋지게 해 줘"는 에이전트가 추측하게 만들지만, /impeccable bolder 가격 카드 처럼 말하면 그 동작 하나를 위해 쓰인 지침서를 불러와 지정한 대상에만 적용합니다. 어디서나 보이는 Inter 글꼴, 보라-파랑 그라데이션, 카드 안의 카드 같은 'AI 슬롭' 특징을 잡아내는 규칙 62개도 들어 있습니다.

안에 뭐가 있나요?

조정: bolder, quieter, distill, colorize, typeset, layout, animate, delight, overdrive. 검토: critique(사용성 점수 매기기), audit(접근성·성능·테마·반응형을 P0~P3로 등급화). 마무리: polish, harden, clarify, adapt, optimize, onboard. 실시간: live, generate. 준비: shape, init, document, extract. 총 24개 명령입니다.

쓰는 법

프로젝트마다 /impeccable init 을 한 번 실행하면 코드를 읽고 몇 가지만 물어 PRODUCT.md를 씁니다. /impeccable document 는 기존 비주얼 체계를 DESIGN.md로 남겨 브랜드가 흐트러지지 않게 합니다. 그다음 /impeccable critique 온보딩 화면 처럼 '명령 + 대상'으로 부릅니다. 대상을 좁게 잡을수록 결과가 좋습니다.

주의할 점

이미 존재하는 화면을 다듬는 데 가장 강하고, 새 페이지를 처음부터 만드는 것은 더 어려운 모드라고 문서가 밝힙니다.
