이게 뭐예요?

Exa는 AI를 위해 만든 검색 엔진입니다. 키워드가 아니라 '의미'로 찾아서, 보통 검색보다 관련 글을 잘 찾습니다. 이 플러그인은 웹 검색, 깊은 조사(여러 출처를 읽고 보고서 작성), 페이지 본문 추출을 Claude에 줍니다.

설치와 첫 사용

exa.ai에서 API 키를 받습니다(무료 크레딧 있음). 딸깍 설치 뒤 "이 주제로 최근 한 달 글 찾아서 출처랑 정리해 줘"처럼 말하면 됩니다.
