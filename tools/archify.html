Archify

여행 일정, 공부 계획, 시스템 구조 등 무엇이든 말로 설명하면 클릭하며 탐색할 수 있는 HTML 다이어그램으로 만들어 줍니다.

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

복잡한 것을 그림으로 정리해서 공유하고 싶은 사람. Node.js가 있으면 그림 생성과 검증까지 됩니다

사용 예시

  • "Archify로 우리 가족 제주 3박4일 일정을 지도처럼 그려 줘"
  • "Archify로 이 저장소의 요청 처리 흐름을 다이어그램으로 그리고 캐시 미스 경로를 강조해 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

이해하거나 계획하거나 공유하고 싶은 것을 인터랙티브 비주얼로 바꿔 주는 무료 오픈소스 스킬입니다. 아이디어·질문·계획을 말로 설명하면 탐색하고 꾸미고 공유할 수 있는 HTML 파일을 만듭니다. 여행 일정과 학습 지도부터 복잡한 시스템 구조까지 다룹니다. 저장소가 없어도 되고, 저장소를 읽혀 '한 문장으로 코드 지도 만들기'도 가능합니다.

안에 뭐가 있나요?

archify(다이어그램 생성 본체, 스키마와 예시 포함)와 archify-review(검토)가 있습니다. Claude Code, Codex CLI, OpenCode에서는 전체 렌더러와 검증 흐름이 동작하고, Claude.ai에는 archify.zip을 업로드해 쓸 수도 있습니다.

쓰는 법

설치 뒤 "Archify로 웹 요청 흐름을 그려 줘: 브라우저가 API 호출, API가 Redis 확인, 캐시 미스면 PostgreSQL 조회 후 캐시 채움"처럼 말하고, 이어서 "인증 추가", "캐시 미스 경로 강조", "밝은 테마로"라고 고쳐 나갑니다.

주의할 점

Mermaid 자동 변환, 범용 자동 배치, 호스팅 공유, 위지윅 편집은 의도적으로 범위 밖입니다. 온라인 유료 서비스들은 제3자가 운영하며 Archify 공식이 아니라고 README가 밝힙니다.
