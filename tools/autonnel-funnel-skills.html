원문 설명 한글판

이게 뭔가요?

세일즈 퍼널을 만들고 고치는 스킬 6개입니다. '랜딩페이지가 전환이 안 돼요', '이걸 온라인에서 팔아야 해요'를 에이전트가 실제로 할 수 있는 일로 바꿔 줍니다: 뻔한 체크리스트 대신 영향 순으로 정렬된 점검표, 그림이 아닌 바로 만들 수 있는 퍼널 명세, 결제 요건까지 포함한 원클릭 업셀 설계, iOS에서도 살아남는 7단계 추적 체인, 비용 교차점을 계산한 플랫폼 추천.

안에 뭐가 있나요?

landing-page-conversion-audit(트래픽은 있는데 안 팔리는 페이지의 수정 목록), sales-funnel-blueprint(상품을 페이지별 퍼널·가격 사다리·단계별 목표로), post-purchase-upsell-flow(결제 후 추가 판매), server-side-conversion-tracking(전환이 적게 잡힐 때), funnel-platform-picker(호스팅형·플러그인·자체 호스팅 중 선택), self-hosted-funnel-launch(Autonnel 직접 설치·운영). 이 순서대로 이어 쓰면 하나의 전체 프로젝트가 됩니다.

주의할 점

README 스스로 밝히는 것: 영업용 홍보가 아니며 자체 호스팅이 틀린 답일 때를 각 스킬이 말해 줍니다. 스킬 안의 지표 범위는 인용할 벤치마크가 아닌 출발점입니다. Autonnel 자체는 Apache-2.0 자체 호스팅 퍼널 빌더로 Cloudflare Workers에 배포합니다.
