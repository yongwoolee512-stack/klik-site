이런 분께

Gmail 정리, 드라이브 파일 검색, 캘린더 일정 추가를 Claude에 맡기고 싶은 분. 단, 구글 클라우드 프로젝트를 만들어 OAuth 인증을 직접 설정해야 해서 개발 경험이 없으면 첫 설정이 어렵습니다

사용 예시

  • "gws로 이번 주 받은 메일 중 첨부파일 있는 것만 목록으로 보여 줘"
  • "내 드라이브에서 '견적'이 들어간 파일 찾아서 최근 5개 알려 줘"
  • 95개 중 핵심: gws-gmail, gws-drive, gws-calendar, gws-sheets, gws-docs (각 서비스 1개씩 골라 설치도 가능)

깃허브 원문 설명 한글판

이게 뭔가요?

구글 워크스페이스 전체(드라이브, Gmail, 캘린더, 시트, 문서, 챗, 관리 등)를 다루는 명령줄 도구 gws입니다. 명령 목록을 고정해 두지 않고 구글의 Discovery 서비스를 실행 시점에 읽어 명령을 만들기 때문에 구글이 API를 추가하면 자동으로 따라옵니다. 결과는 모두 구조화된 JSON이라 AI 에이전트가 쓰기 좋습니다. README는 '공식 지원 구글 제품이 아니며' v1.0 전까지 호환성이 깨질 수 있다고 밝힙니다.

안에 뭐가 있나요?

저장소에 SKILL.md가 95개 있습니다. 지원 API마다 하나씩(gws-drive, gws-gmail, gws-calendar, gws-sheets, gws-docs 등)과 자주 하는 작업용 레시피 50개, 공용 gws-shared 스킬입니다. 전부 설치하거나 npx skills add 로 특정 스킬 폴더만 설치할 수 있습니다.

쓰는 법

준비물은 Node.js 18 이상(또는 릴리스에서 실행 파일 다운로드), 구글 클라우드 프로젝트, 구글 계정입니다. gws auth setup 이 클라우드 프로젝트 생성과 로그인을 안내하는데 gcloud CLI가 필요하고, 없으면 구글 클라우드 콘솔에서 OAuth 클라이언트(데스크톱 앱)를 직접 만들어 ~/.config/gws/client_secret.json 에 저장한 뒤 gws auth login 을 합니다. 그다음 gws drive files list 같은 명령을 쓰거나 Claude에게 맡깁니다.

주의할 점

OAuth 앱이 미검증(테스트) 상태면 구글이 동의 범위를 약 25개로 제한해 recommended 프리셋(85개 이상)이 실패하니 gws auth login -s drive,gmail,sheets 처럼 서비스를 골라 로그인하라고 합니다. 테스트 사용자에 본인 이메일을 반드시 추가해야 하며 빠뜨리면 'Access blocked' 오류가 납니다. 자격 증명은 AES-256-GCM으로 암호화해 OS 키링에 저장됩니다. 첫 설정이 개발자 수준이라 비개발자에게는 문턱이 높습니다.
