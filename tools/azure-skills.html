Azure Skills Plugin

마이크로소프트 클라우드 Azure에 앱을 올리고, 비용을 점검하고, 문제를 진단하는 방법을 Claude가 알게 해 주고 Azure 도구 200여 개를 연결합니다.

딸깍에서 한 번에 설치하기

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

Azure를 쓰는 개발자·운영자. Azure 계정, Node.js, Azure CLI 로그인이 필요한 개발자용 도구입니다

사용 예시

  • "이 앱을 Azure에 배포하려면 어떤 서비스가 맞는지 정리하고 준비해 줘"
  • "지난달 Azure 비용이 왜 늘었는지 진단해 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

마이크로소프트가 만든 Azure 클라우드용 플러그인입니다. 'Azure 작업은 코드 문제가 아니라 결정 문제'라는 생각으로, 어떤 서비스를 쓸지·배포 전 무엇을 검증할지 같은 판단 지침(스킬)과, 실제로 Azure 자원을 조회·조작하는 도구(Azure MCP 서버, 200개 이상)를 한 번에 설치합니다. Microsoft Foundry용 AI 모델 도구도 포함됩니다.

안에 뭐가 있나요?

빌드·배포(azure-prepare, azure-validate, azure-deploy, azure-kubernetes 등), 진단·모니터링·거버넌스(azure-diagnostics, azure-compliance, azure-quotas 등), 비용·아키텍처 최적화(azure-cost, azure-compute, azure-cloud-migrate 등), 데이터·AI·인증(azure-ai, azure-storage, azure-rbac, microsoft-foundry 등) 스킬이 들어 있습니다.

준비물

Azure 계정, Node.js 18 이상, Azure CLI(az login 완료), 배포까지 하려면 Azure Developer CLI(azd auth login)가 필요합니다. Claude Code에서는 /plugin install azure@claude-plugins-official 로도 설치할 수 있습니다.

주의할 점

실제 클라우드 자원을 만들고 지울 수 있으므로 비용이 발생할 수 있습니다. 클라우드 운영 경험이 있는 사람을 위한 도구입니다.
