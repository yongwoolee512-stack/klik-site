이런 분께

구글 클라우드에서 AI 에이전트를 만들려는 개발자. Python 3.11, uv, Node.js, 구글 클라우드 계정이 필요한 개발자용 도구입니다

사용 예시

  • "agents-cli로 고객 문의를 분류해 주는 에이전트 만들어서 배포해 줘"
  • "방금 만든 에이전트 평가 데이터셋 만들어서 점수 매겨 줘"

이게 뭔가요?

구글이 만든 'Gemini 플랫폼용 에이전트 개발 CLI와 스킬'입니다. 내가 쓰는 코딩 도우미(Claude Code, Codex, Antigravity 등)에 구글 클라우드 위에서 기업용 에이전트를 만들고, 키우고, 관리하는 전문 지식을 넣어 줍니다.

안에 뭐가 있나요?

google-agents-cli-workflow(개발 수명주기와 모델 선택), -adk-code(ADK 파이썬 API로 에이전트·도구·상태 작성), -scaffold(프로젝트 생성·업그레이드), -eval(평가 방법: 지표, 데이터셋, LLM 심사), -deploy(Agent Runtime, Cloud Run, GKE 배포와 CI/CD), -publish(Gemini 등록), -observability(추적·로그) 7개 스킬이 있습니다.

쓰는 법

uvx google-agents-cli setup 으로 CLI와 스킬을 함께 설치하거나 스킬만 설치한 뒤, "agents-cli로 ~하는 에이전트 만들어 줘"라고 말합니다. agents-cli create, eval run, deploy, publish gemini 등 명령을 Claude가 대신 실행합니다.

주의할 점

Python 3.11 이상, uv, Node.js가 필요하고 구글 클라우드 로그인이 필요합니다. 배포하면 클라우드 비용이 발생할 수 있습니다.
