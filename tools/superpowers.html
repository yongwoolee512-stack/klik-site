이런 분께

뭘 시키면 Claude가 바로 코드를 쏟아내서 결국 엉망이 되는 경험을 한 분

사용 예시

  • "회원가입 기능 만들어 줘"라고 해 보세요. 바로 코딩하지 않고 뭘 원하는지 먼저 짧게 묻습니다.
  • 설계에 동의하면 계획서를 쓰고, '시작'이라고 하면 보조 에이전트들이 몇 시간씩 혼자 일합니다.
  • 테스트 먼저 쓰기(TDD), 필요 없는 건 안 만들기(YAGNI)가 기본값입니다.

원문 설명 한글판

슈퍼파워란?

코딩 에이전트를 위한 '완성된 소프트웨어 개발 방법론'입니다. 서로 조합되는 스킬 묶음과, 에이전트가 그 스킬을 꼭 쓰게 만드는 초기 지시문으로 되어 있습니다.

어떻게 일하나

에이전트를 켜는 순간부터 시작됩니다. 뭔가 만들려는 걸 알아채면 바로 코드로 뛰어들지 않고, 한 발 물러서서 '진짜 뭘 하려는 건지' 묻습니다. 대화에서 요구 사항을 뽑아내면 읽고 소화할 수 있을 만큼 짧은 덩어리로 보여 줍니다.

설계에 동의하면 '의욕은 넘치지만 취향 없고 판단력 없고 프로젝트 맥락 모르고 테스트 싫어하는 신입'도 따라갈 수 있을 만큼 명확한 구현 계획을 씁니다. 진짜 빨강/초록 TDD, YAGNI(필요 없는 건 안 만든다), DRY(반복 금지)를 강조합니다.

'시작'이라고 하면 보조 에이전트 주도 개발이 돌아갑니다. 에이전트들이 과제를 하나씩 처리하고, 서로 검토하고, 다음으로 넘어갑니다. 계획에서 벗어나지 않고 몇 시간씩 혼자 일하는 게 흔합니다. 스킬이 자동으로 발동되니 따로 할 건 없습니다.

설치

Anthropic 공식 플러그인 마켓플레이스에 올라 있습니다: /plugin install superpowers@claude-plugins-official. 딸깍이 이 명령을 대신합니다. 제작자 자체 마켓(obra/superpowers-marketplace)도 있고, Codex·Cursor·Gemini CLI·Copilot CLI 등 15개 이상의 다른 에이전트용 설치법도 README에 있습니다. 여러 에이전트를 쓰면 각각 설치해야 합니다.

안에 든 스킬

테스트: test-driven-development(빨강-초록-리팩터 사이클).
디버깅: systematic-debugging(4단계 근본 원인 추적), verification-before-completion(정말 고쳐졌는지 확인), diagnosing-superpowers(세션에서 뭐가 잘못됐는지 증거로 밝히기).
협업: brainstorming(의도 끌어내기), writing-plans, executing-plans, dispatching-parallel-agents(병렬 보조 에이전트), requesting/receiving-code-review, using-git-worktrees, finishing-a-development-branch(머지/PR 결정), subagent-driven-development(2단계 검토).
메타: writing-skills(새 스킬 만들기), using-superpowers(입문).

철학

테스트 먼저, 항상. 즉흥보다 체계. 복잡성 줄이기가 제1 목표. 주장보다 증거: 끝났다고 말하기 전에 확인. 기업용 상용 지원은 primeradiant.com으로 문의. 새 스킬 기여는 일반적으로 받지 않으며, 모든 지원 에이전트에서 동작해야 합니다.
