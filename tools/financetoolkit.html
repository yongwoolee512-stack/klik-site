  • "애플과 마이크로소프트 최근 5년 PER 비교해 줘"

깃허브 원문 설명 한글판

이게 뭐예요?

기업 재무 분석을 투명하고 효율적으로 하는 파이썬 패키지 Finance Toolkit의 MCP 서버입니다. 같은 지표(예: PER)가 사이트마다 다르게 나오는 문제에서 출발해, 계산식을 공개하고 일관되게 계산합니다. 500개 이상 메서드를 코드 없이 Claude 등에서 조회합니다.

주요 기능

섹터 탐색, 시장 추적, 경쟁사 비교, 위험·수익 측정, 옵션 시장 기대치, 경제 환경 지표, 섹터 ETF 비교, 분산 포트폴리오 구성과 추적.

설치

호스팅 서버 https://financetoolkit.jeroenbouma.com/mcp 에 연결하면 첫 사용 때 OAuth가 처리합니다. 로컬 실행은 uvx 로 설정하며 Financial Modeling Prep API 키를 씁니다.

주의

기본 데이터 소스는 Financial Modeling Prep이며 무료 플랜은 조회 한도가 있습니다. 투자 조언이 아닌 데이터 도구입니다.
