이게 뭐예요?

Claude Code와 Codex용 에이전트 메타 하네스입니다. 모델 주변에 도구·메모리·루프·샌드박스·제어를 붙여 100개 이상의 전문 에이전트, 스웜 조정, 자가 학습 메모리, 기기 간 연합 통신, 보안 가드레일을 더합니다. 2025년 6월 Claude Flow로 시작한 프로젝트입니다. MIT.

설치와 사용

Claude Code 2.1.287 이상에서 /plugin marketplace add ruvnet/ruflo 뒤 ruflo-core, ruflo-console, ruflo-mods 를 설치하고 /reload-plugins, /ruflo. 다른 MCP 클라이언트는 npx ruflo@latest init wizard 로 설정합니다.

작동 방식

사용자 → Ruflo(CLI/MCP) → 라우터 → 스웜 → 에이전트 → 메모리 → LLM 순으로 흐르고, 메모리가 경험을 라우팅에 되먹입니다. init 뒤에는 평소처럼 Claude Code를 쓰면 훅이 작업을 자동 분배합니다.

주의

모드(mods)는 내 계정 권한으로 실행되니 설치 전 코드를 검토하라고 README가 안내합니다. MCP 도구 314개, CLI 명령 26개로 규모가 큽니다.
