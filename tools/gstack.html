깃허브 원문 설명 한글판

지스택이란?

Claude Code(와 다른 코딩 에이전트)를 '가상 엔지니어링 팀'으로 바꿉니다. 제품을 다시 생각하는 CEO, 아키텍처를 확정하는 엔지니어링 매니저, AI 티 나는 디자인을 잡는 디자이너, 운영에서 터질 버그를 찾는 검토자, 진짜 브라우저를 여는 QA 책임자, OWASP+STRIDE 보안 감사를 하는 보안 담당, PR을 내보내는 릴리스 엔지니어. 전부 슬래시 명령, 전부 마크다운, 전부 무료, MIT.

제작자는 Y컴비네이터 대표 Garry Tan입니다. 매일 쓰는 오픈소스 '소프트웨어 공장'을 모두가 쓸 수 있어야 한다며 공개했습니다. 대상: 직접 만들고 싶은 기술 창업자, 빈 프롬프트 대신 구조화된 역할이 필요한 Claude Code 초보, 모든 PR에 엄격한 검토·QA·배포 자동화를 원하는 리드 엔지니어.

빠른 시작

1) 설치(붙여넣기 두 번, 30초). 2) /office-hours 를 치고 만들려는 걸 설명하면 기획을 되묻고 다른 스킬이 읽는 설계 문서를 씁니다. 3) 변경이 있는 브랜치에서 /review 를 치면 CI는 통과하지만 운영에서 깨지는 버그를 찾아 고칩니다. 4) /qa 를 스테이징 주소에 쓰면 진짜 브라우저를 열어 버그를 재현하고 고칩니다.

여기까지 해 보면 맞는지 알게 됩니다. 전체 스프린트를 원하면 /autoplan 이 계획을 끝까지 검토하고 /ship 이 테스트·검토·PR을 돌립니다.

설치: 왜 딸깍 한 번이 안 되나

필요한 것: Claude Code, Git, Bun 1.4.2 이상(1.3.3 미만은 컴파일된 도구가 프로젝트의 .env를 읽을 수 있어 거부), 윈도우는 Node.js도. 맥은 Aside 브라우저를 권장(없으면 자체 브라우저를 빌드).

1단계: Claude Code를 열고 README의 설치 문장을 붙여 넣습니다. 'git clone ... ~/.claude/skills/gstack && ./setup 을 실행하고, CLAUDE.md에 gstack 섹션을 추가하라'는 내용이고, 나머지는 Claude가 합니다. 딸깍 사이트의 '설치 명령 복사'가 바로 이 문장입니다.

2단계(선택, 팀 모드): 저장소 안에서 ./setup --team 과 gstack-team-init 을 실행해 커밋하면 팀원이 자동으로 gstack을 받습니다. 매 세션 시작 때 조용히 업데이트를 확인하고(시간당 1회), 월·목 태그된 안정판만 따릅니다.

그 밖에

Codex·Cursor 등 다른 에이전트에서도 돌아갑니다(./setup 이 알아서 감지). /cso(보안 담당)는 네이티브 빌드 도구가 필요해 없으면 비활성으로 남겨 둡니다. 삭제 방법은 docs/uninstall.md. 생산성 수치와 스프린트 10개를 동시에 돌리는 이야기는 docs/why-gstack.md에 있습니다.
