skills.sh 원문 설명 한글판

이게 뭔가요?

Solana Foundation이 만든 솔라나 개발용 에이전트 스킬입니다. 2026년 7월 기준 모범 사례를 담았고, Claude Code·Codex·Copilot·Gemini CLI·Cursor·Windsurf·Cline·OpenCode 등 SKILL.md를 읽는 모든 에이전트에서 동작합니다.

안에 뭐가 있나요?

@solana/kit 8 SDK와 트랜잭션 v1, 지갑 연결(Wallet Standard), 구형 web3.js 마이그레이션, Anchor 1.2와 Pinocchio 프로그램 개발, Surfpool·LiteSVM·Mollusk 테스트, Codama 코드 생성, 보안 취약점 패턴, 결제·수수료 대납(Kora)·서버 서명(Keychain)·토큰 발행(Mosaic), 툴체인 버전 호환과 오류 해결 가이드가 참고 문서로 들어 있습니다.

쓰는 법

npx skills add solana-foundation/solana-dev-skill 한 줄로 설치되며, 저장소의 install.sh나 수동 복사, 데스크톱 앱용 zip 업로드도 지원합니다. 설치 후 "Next.js 앱에 솔라나 지갑 연결 설정해 줘", "에스크로용 Anchor 프로그램 만들어 줘", "이 프로그램 보안 검토해 줘"처럼 물으면 자동으로 적용됩니다.

주의할 점

SDK·프로그램 프레임워크·테스트 도구에 대해 정해진 기본 선택(opinionated)을 따릅니다. 블록체인 개발 지식이 전제되는 개발자용 스킬입니다. GitHub의 Code → Download ZIP은 폴더 구조가 깊어 업로드가 안 되니 릴리스의 solana-dev.zip을 쓰라고 안내합니다.
