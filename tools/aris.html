이게 뭐예요?

ARIS(Auto-Research-In-Sleep)는 머신러닝 연구를 자율 진행하는 마크다운 기반 스킬 묶음입니다. 플랫폼이 아니라 방법론이라고 소개하며 Claude Code, Codex CLI, Cursor 등 어디서든 씁니다. 실행 모델이 일하고 독립된 모델(기본 Codex MCP)이 검토하는 구조입니다. 논문도 공개됐습니다.

주요 기능

/aris:idea-discovery(아이디어 발굴), /aris:paper-writing(논문 작성), 문헌 조사(/research-lit, Gemini·OpenAlex 소스), 논문 그림 생성 등. 실제 논문이 환각 인용으로 잘못 보고되는 문제 수정 등 지속 업데이트.

설치와 사용

플러그인 설치 뒤 /aris:setup 을 한 번 실행해 플러그인에 포함된 Codex 검토 브리지를 등록하고 Claude Code를 재시작합니다. 갱신은 claude plugin update aris@aris.

주의

검토용 외부 모델(Codex 등) 연결이 필요하고 사용료가 들 수 있습니다. 연구자용 도구입니다.
