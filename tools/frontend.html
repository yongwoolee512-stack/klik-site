깃허브 원문 설명 한글판

이 저장소는?

Anthropic이 운영하는 Claude Code 공식 플러그인 디렉터리입니다. Anthropic이 만든 플러그인(plugins 폴더)과 파트너·커뮤니티가 올린 플러그인(external_plugins 폴더)이 모여 있습니다.

주의사항 (원문 경고)

플러그인을 설치·사용하기 전에 믿을 수 있는지 꼭 확인하세요. Anthropic은 플러그인 안에 어떤 서버·파일·프로그램이 들어 있는지 통제하지 않으며, 의도대로 동작하는지 보증하지 않습니다. 딸깍은 그래서 공식·검증 등급을 붙입니다.

frontend-design이 하는 일

웹 화면을 만들 때 '어디서나 본 듯한 AI 디자인'(보라색 그라데이션, 기본 글꼴, 가운데 정렬 일변도)을 피하고, 주제에 맞는 글꼴·색·배치를 고르도록 Claude를 이끕니다. 랜딩페이지, 포트폴리오, 소개 페이지에 특히 효과가 큽니다.

써 보기

설치 후 Claude Code에 "카페 소개 페이지 만들어 줘"처럼 말하면 됩니다. 원하는 분위기(고급스럽게, 발랄하게)를 한마디 덧붙이면 더 좋습니다.
