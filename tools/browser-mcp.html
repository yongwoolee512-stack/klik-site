이런 분께

로그인이 필요한 사이트 작업을 AI에게 맡기고 싶은 분

사용 예시

  • "내 크롬에서 ○○ 사이트 열고 이번 달 주문 내역 정리해 줘"
  • AI는 자기 탭을 따로 열어 쓰므로 내가 보던 탭은 그대로예요.

깃허브 원문 설명 한글판

이게 뭐예요?

Claude Code, Cursor, VS Code, Codex, Claude Desktop 같은 AI 앱이 '내 크롬'을 쓰게 해 주는 도구입니다. 내가 로그인해 둔 사이트와 프로필을 그대로 쓰되, AI는 자기 탭을 따로 열어 작업합니다. 모든 동작이 내 컴퓨터 안에서 돌아갑니다.

어떻게 동작해요?

AI 앱마다 MCP 서버(`npx @browsermcp/mcp@latest`)가 돌고, 이 작은 프로세스가 사용자당 하나인 데몬을 띄워 AI의 browser 도구 호출을 넘겨 줍니다. 데몬은 크롬 확장을 통해 Playwright로 탭을 조작합니다. 확장은 크롬 웹 스토어에서 받습니다.

첫 사용

AI 앱을 재시작하고 브라우저에서 할 일을 시키면, 처음엔 확장 팝업이 이 컴퓨터의 서버를 '허용'할지 묻습니다. 직접 빌드하고 싶은 사람을 위한 안내도 있지만 일반 사용자는 웹 스토어 확장과 npm 서버만으로 충분합니다. 라이선스는 Apache 2.0입니다.
