이게 뭔가요?

Supabase가 공식으로 내놓은 에이전트 스킬 모음입니다. 스킬은 AI가 특정 작업을 더 정확히 하도록 돕는 안내서·스크립트 폴더로, Claude Code·Copilot·Cursor·Cline 등 18개 이상 에이전트와 호환됩니다.

안에 뭐가 있나요?

supabase 스킬은 데이터베이스·Auth·Edge Functions·Realtime·Storage·Vectors·Cron·Queues 등 Supabase 제품 전반과 Next.js·React·SvelteKit 연동, 로그인·세션·RLS 문제 해결, CLI와 MCP 사용, 마이그레이션과 보안 점검을 다룹니다. supabase-postgres-best-practices 스킬은 쿼리 성능, 연결 관리, 스키마 설계, 잠금, RLS 보안 등 8개 범주의 Postgres 최적화 지침을 중요도 순으로 담았습니다.

쓰는 법

npx skills add supabase/agent-skills로 전부 설치하거나 --skill 옵션으로 하나만 고를 수 있고, Claude Code에서는 마켓플레이스를 추가한 뒤 supabase@supabase-agent-skills 플러그인으로 설치할 수도 있습니다. 설치 후엔 "이 쿼리 최적화해 줘", "스키마 성능 검토해 줘"처럼 말하면 알아서 적용됩니다.

주의할 점

데이터베이스와 백엔드 개발 용어가 전제되는 개발자용 스킬입니다. Supabase를 쓰는 프로젝트가 아니라면 쓸 일이 없습니다.
