이게 뭐예요?

보안 감사 회사 Trail of Bits가 AI 보조 보안 분석·테스트·개발용으로 공개한 스킬 마켓플레이스입니다. Claude Code, Codex, ChatGPT 워크스페이스에서 설치할 수 있습니다.

들어 있는 것

코드 변경 보안 리뷰(differential-review), 정적 분석, 변종 분석, 스마트 컨트랙트 보안, 속성 기반 테스트, 뮤테이션 테스트, Semgrep 룰 작성, 공급망 위험 감사, C·Rust·파이썬 리뷰 등 46개 플러그인.

설치와 사용

/plugin marketplace add trailofbits/skills 뒤 /plugin menu 에서 원하는 플러그인을 골라 설치합니다. 딸깍은 그중 differential-review 를 기본으로 설치합니다.
