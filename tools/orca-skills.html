이게 뭔가요?

Orca는 Codex, Claude Code, OpenCode, Pi 같은 코딩 에이전트를 나란히 실행하되 각각 독립된 git worktree에 격리하고 한 곳에서 추적하는 데스크톱 앱(IDE)입니다. 같은 요청을 에이전트 다섯에 뿌려 결과를 비교하고 가장 좋은 것을 합치는 식의 작업, 터미널 분할, 브라우저에서 UI 요소를 클릭해 프롬프트로 보내는 디자인 모드, GitHub·Linear 연동, 휴대폰 동반 앱 등을 제공합니다.

스킬은 무엇을 하나요?

저장소의 skills 폴더에 orca-cli(Orca가 관리하는 worktree·터미널·브라우저를 orca 명령으로 조작), orchestration(에이전트 지휘), computer-use, orca-linear, orca-jira, orca-emulator 등이 있습니다. 각 스킬은 '발견용 스텁'으로, 실제 안내는 현재 설치된 Orca 실행 파일에서 버전에 맞게 불러옵니다(ORCA skills get orca-cli).

주의할 점

Orca 앱이 설치돼 있지 않으면 스킬이 할 수 있는 일이 없습니다. 리눅스에서는 bare orca 명령이 GNOME 화면 읽기 프로그램과 겹치므로 orca-ide를 쓰라고 안내합니다.
