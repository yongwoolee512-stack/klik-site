이런 분께

AI가 만든 화면이 '어디서 본 듯한 템플릿' 같아서 고민인 사람. 기본 스킬은 계정 없이 쓰고, 실제 앱 화면 검색은 유료 MCP가 필요합니다

사용 예시

  • "image-to-ui로 이 스크린샷을 우리 앱에 1:1로 구현해 줘. 새로 디자인하지 말고 같은 화면 크기에서 비교해서 차이를 고쳐 줘"
  • "ui-design으로 결제 설정 페이지 개선해 줘. 로딩·빈 화면·오류 상태도 포함해서"

skills.sh 원문 설명 한글판

이게 뭔가요?

'코딩 에이전트를 위한 더 나은 UI'를 내건 UIZZE의 스킬 모음입니다. Codex, Claude Code, Cursor, Copilot에 집중된 UI 작업 흐름을 주고, 원하면 실제 웹·iOS 화면 80만 장 이상을 참고 자료로 연결합니다.

안에 뭐가 있나요?

uizze-ui(공식 UI 팩: 내 프로젝트 코드와 디자인 토큰을 바탕으로 디자인 시스템, 실제 앱 예시, 글꼴·아이콘·모션 활용), ui-design(명확한 위계와 필요한 상태를 갖춘 화면 만들기·개선), anti-ui-slop(뻔한 첫 초안을 제품 맞춤으로 고치고 마감 검토), ui-radar(디자인 결정 조사, 유료 MCP 연결 시 실시간 검색), image-to-ui(이미지·스크린샷을 같은 화면 크기에서 비교하며 1:1 구현). UI Taste와 iOS Design 스킬은 uizze.sh에서 별도 배포됩니다.

쓰는 법

설치 뒤 구체적으로 요청합니다. README 예시: "ui-design으로 결제 설정 페이지를 개선해 줘. 현재 요금제·결제 수단·청구서를 한눈에 보이게, 우리 컴포넌트와 디자인 토큰을 재사용하고, 로딩·빈 화면·오류·권한 상태를 포함하고, 데스크톱과 모바일 크기에서 확인해 깨지는 걸 고쳐 줘."

주의할 점

로컬 UI 작업은 계정이나 MCP 연결 없이 됩니다. 실제 제품 화면 검색(참고 자료 검색)은 유료 MCP입니다. PR 검사용 GitHub Action도 제공합니다.
