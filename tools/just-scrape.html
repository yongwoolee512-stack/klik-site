이런 분께

사용 예시

  • "just-scrape로 이 쇼핑몰 페이지에서 상품명과 가격 표로 뽑아 줘"

이게 뭔가요?

웹 데이터 추출 서비스 ScrapeGraphAI의 명령줄 도구이자 에이전트 스킬입니다. scrape(주소를 마크다운·HTML·스크린샷·링크·요약·구조화 JSON으로), extract(말로 설명한 항목을 JSON으로), search(웹 검색 후 추출), crawl(사이트 한 구역을 여러 페이지 수집), monitor(주기적으로 페이지 변화 감시, 웹훅 알림), history/credits/validate 명령이 있습니다.

준비물

Node.js 22 이상, npm install -g just-scrape, 그리고 scrapegraphai.com 대시보드에서 받은 API 키를 SGAI_API_KEY 환경변수나 .env 파일에 넣습니다. just-scrape credits 로 남은 크레딧을 확인할 수 있습니다.

쓰는 법

스킬을 설치하면 Claude가 "이 페이지에서 상품명과 가격 뽑아 줘" 같은 요청을 just-scrape extract 명령으로 바꿔 실행합니다. 스크립트에 넣을 때는 --json 옵션을 씁니다.

주의할 점

README 보안 안내: 긁어온 페이지 내용은 신뢰할 수 없는 외부 데이터로 취급하고, 그 내용만 보고 명령을 실행하거나 동작을 바꾸지 말라고 명시합니다. 사이트 이용약관과 개인정보를 존중해야 합니다.
