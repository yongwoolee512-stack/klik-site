agent-browser

Claude가 웹사이트를 열고, 버튼을 누르고, 글자를 입력하고, 화면을 캡처하도록 해 주는 빠른 브라우저 조작 도구입니다.

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

웹에서 반복되는 클릭·입력 작업을 맡기거나, 내가 만든 사이트가 제대로 동작하는지 확인시키고 싶을 때. npm 설치가 필요합니다

사용 예시

  • "agent-browser로 우리 쇼핑몰 주문 페이지 열어서 끝까지 진행되는지 확인해 줘"
  • "이 사이트 접속해서 공지사항 제목들만 뽑아 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

AI 에이전트용 브라우저 자동화 명령줄 도구입니다. Rust로 만든 네이티브 프로그램이라 빠르고, Claude가 명령 한 줄씩 보내서 웹페이지를 열고(open), 화면 구조를 읽고(snapshot), 클릭하고(click), 입력하고(fill), 스크린샷을 찍을 수 있습니다.

어떻게 동작하나요?

snapshot 명령이 페이지의 접근성 트리를 읽어 각 요소에 @e1, @e2 같은 짧은 참조 번호를 붙입니다. Claude는 그 번호로 "@e2 클릭", "@e3에 이메일 입력"처럼 정확하게 조작합니다. 요소가 숨겨져 있거나 다른 창에 가려져 있으면 성공한 척하지 않고 바로 실패를 알려 줍니다. CSS 선택자 같은 전통 방식도 지원합니다.

설치

npm install -g agent-browser 후 agent-browser install 로 테스트용 Chrome을 한 번 내려받습니다(이미 설치된 Chrome·Brave 등이 있으면 자동 인식). 맥은 Homebrew, Rust 사용자는 cargo로도 설치할 수 있습니다. Claude Code에서는 플러그인으로 설치하면 스킬이 함께 들어옵니다.

주의할 점

브라우저가 실제로 사이트에 접속해 행동하므로 로그인 정보나 결제처럼 민감한 작업은 직접 하고, 읽기·확인 위주로 맡기는 것이 안전합니다. 리눅스에서는 추가 시스템 라이브러리 설치가 필요할 수 있습니다.
