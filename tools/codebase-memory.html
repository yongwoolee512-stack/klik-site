  • "이 함수 누가 호출해?"
  • "이 파일 바꾸면 영향 받는 테스트 찾아 줘"
  • 처음 한 번 색인하면 다음 세션에도 그대로 남아요.

깃허브 원문 설명 한글판

이게 뭐예요?

소스 코드, 문서, 설정, 인프라를 하나의 영구 로컬 그래프로 연결해 두는 MCP 서버입니다. 코딩 에이전트에게 구조적 맥락을 주는 것이 핵심이고, 순수 C로 만든 백엔드가 17개 MCP 도구를 제공하며 162개 언어·파일 형식을 파싱합니다. 심볼·텍스트·의미 검색을 호출자, 의존성, 코드 조각과 함께 돌려 주어 토큰 사용을 줄입니다.

무엇을 연결하나

문서 섹션·PDF·아키텍처 결정을 코드에 연결하고, Docker·Kubernetes·Helm·Terraform·Ansible·CI 설정까지 관계를 따라갑니다. 변경 전 영향 받는 심볼과 관련 테스트를 찾아 주고(실험적 Smart CI), 색인은 세션 사이에 유지됩니다. CBM Lens(오픈 베타)라는 시각화 도구가 함께 들어 있어 폴더·파일·심볼의 관계를 지도처럼 봅니다.

Claude Code 플러그인으로 설치

이 저장소는 플러그인 마켓플레이스이기도 합니다. `claude plugin marketplace add DeusData/codebase-memory-mcp` 뒤 `claude plugin install codebase-memory@codebase-memory`. 플러그인은 MCP 서버만 등록하며 `npx -y codebase-memory-mcp@<버전>`으로 시작하고, 첫 실행 때 npm 패키지를 통해 릴리스 바이너리를 받아 체크섬을 검증합니다. 스킬·에이전트 3종·훅은 별도 `codebase-memory-mcp install`로 넣습니다. 둘을 같이 쓰면 서버가 두 번 돌아가니 하나만 고르세요.

안전

분석과 그래프 저장은 모두 내 컴퓨터에서 이루어지고 호스팅 서비스가 없습니다. 모든 릴리스를 SLSA 3와 VirusTotal로 검증하고 OpenSSF Scorecard를 공개합니다. CBM Lens의 로컬 모델은 켠 뒤에만 내려받고 추론은 기기 안에서 합니다. MIT 라이선스이며 arXiv 논문이 있습니다.
