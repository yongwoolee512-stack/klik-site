클로드 기억이란?

Claude Code용 '지속 기억 압축 시스템'입니다. 작업 중 도구 사용 관찰 기록을 자동으로 모으고, 의미 단위로 요약해, 다음 세션에서 쓸 수 있게 넘겨 줍니다. 세션이 끝나거나 다시 연결돼도 Claude가 프로젝트에 대한 지식을 이어 갑니다.

빠른 시작

Claude Code 안에서 두 줄: /plugin marketplace add thedotmack/claude-mem → /plugin install claude-mem. 딸깍이 이 두 줄을 대신합니다. 설치 후 Claude Code를 다시 열면 이전 세션의 맥락이 새 세션에 자동으로 나타납니다.

주의: npm에도 올라 있지만 npm install -g claude-mem 은 '라이브러리만' 설치하고 훅이나 작업자 서비스는 등록하지 않습니다. 반드시 플러그인 명령이나 npx claude-mem install 로 설치하세요.

작동 원리

Claude Code의 훅(hook) 기능으로 세션 시작·도구 사용·세션 종료 시점을 잡아 관찰 기록을 남기고, 별도의 작업자(worker) 서비스가 이를 요약해 저장합니다. 저장된 기억은 검색 도구(MCP)로도 꺼낼 수 있어 '그때 그 오류 어떻게 고쳤지' 같은 질문에 답합니다.

윈도우에서는 훅이 Git Bash 없이 claude-mem 실행 파일을 직접 부릅니다. 'Executable not found' 오류가 나면 npx claude-mem doctor 를 실행하라고 안내합니다.

지원과 주의

Claude Code 외에 OpenCode·Antigravity·Pi 등 다른 에이전트용 설치 옵션(--ide)도 있습니다. Node.js 20 이상. Apache 2.0 라이선스. Vercel 오픈소스 프로그램, Greptile, SerpApi가 후원합니다. 문서는 docs.claude-mem.ai, 32개 언어 README(한국어 포함)가 있습니다.
