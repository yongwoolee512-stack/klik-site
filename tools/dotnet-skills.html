이게 뭐예요?

.NET 팀이 코딩 에이전트용으로 큐레이션한 이식 가능한 스킬과 커스텀 에이전트 저장소입니다. 플러그인별 토큰 사용·시간·통과율을 보는 Skill Value 대시보드도 제공합니다.

플러그인

dotnet(고수준 .NET 스킬 + C# 언어 서버 연동), dotnet-data(EF 데이터 접근), dotnet-diag(성능·디버깅), dotnet-msbuild, dotnet-nuget, dotnet-upgrade(버전 업그레이드), dotnet-maui, dotnet-ai, dotnet-test, dotnet-blazor, dotnet-winforms, dotnet11 등 16개.

설치와 사용

/plugin marketplace add dotnet/skills 뒤 플러그인을 설치하고 재시작합니다. /skills, /agents 로 확인하고 /plugin update 로 갱신합니다. VS Code 플러그인 지원은 프리뷰입니다.
