이런 분께

사용 예시

  • "/convex-setup-auth 이 앱에 로그인 기능 붙여 줘"
  • "/convex-performance-audit 느려진 원인 찾아 줘"

원문 설명 한글판

이게 뭔가요?

백엔드 플랫폼 Convex의 공식 에이전트 스킬입니다. 배경 지식을 늘어놓는 대신 '행동'에 집중한다는 철학으로, 인증 설정·컴포넌트 제작·마이그레이션·성능 진단처럼 구체적인 작업을 완수하도록 설계됐습니다.

안에 뭐가 있나요?

convex(진입점: Convex AI 파일 설치를 권하고 세부 스킬로 안내), convex-quickstart(새 프로젝트 시작 또는 기존 앱에 추가), convex-setup-auth(인증 설정), convex-create-component(경계가 명확한 재사용 컴포넌트), convex-migration-helper(안전한 마이그레이션 계획·실행), convex-performance-audit(성능 병목 조사).

쓰는 법

관련 작업을 감지하면 자동으로 쓰이고, 직접 부를 땐 Claude Code에서 /convex-setup-auth 처럼 슬래시 명령을 씁니다. 모든 스킬을 한 번에 설치하려면 --all 옵션을 씁니다.

주의할 점

개발자용입니다. 인증 같은 UI 관련 스킬은 실제 브라우저 흐름까지 확인하라고 저장소가 권합니다.
