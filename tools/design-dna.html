깃허브 원문 설명 한글판

이게 뭔가요?

시각적 디자인 정체성을 기계가 읽을 수 있는 '디자인 DNA'로 추출·구조화·적용하는 에이전트 스킬입니다. 세 차원으로 봅니다. 디자인 시스템(색, 타이포, 간격, 레이아웃, 형태, 고도, 모션, 컴포넌트 같은 측정 가능한 토큰), 디자인 스타일(분위기, 시각 언어, 구성, 이미지, 인터랙션 느낌, 브랜드 목소리 같은 정성적 인상), 시각 효과(Canvas, WebGL, 3D, 파티클, 셰이더, 스크롤 모션, 커서 효과, 글래스모피즘 등 일반 CSS를 넘는 것). 한국어 README가 있습니다.

어떻게 돌아가나요?

1단계 참고 수집: 닮고 싶은 디자인의 스크린샷·이미지·URL을 모읍니다(여러 개를 합치면 지배적 패턴과 변형을 찾아냄). 2단계 DNA 추출: 모든 시각 속성을 검사해 빈 필드 없는 완전한 JSON 프로필을 만듭니다(충돌은 기록). 3단계 DNA로 생성: DNA JSON과 내 콘텐츠를 주면 원래 디자인 언어를 충실히 재현하되 내 자료에 맞춘 구현(기본은 단일 HTML/CSS/JS)을 만듭니다. 단계는 따로 쓰거나 이어 쓸 수 있고, JSON은 버전 관리·팀 공유·재사용·반복 개선이 가능합니다.

쓰는 법

준비물은 Node.js와 npx. npx skills add zanwei/design-dna (Claude Code만 전역 설치: -a claude-code -g -y). 로컬 클론에서 npx skills add ./design-dna -y 도 됩니다. --list 로 포함 스킬을 봅니다. 스키마 설명은 references/schema.md, 생성 지침은 references/generation-guide.md에 있습니다.

주의할 점

'저 사이트처럼'이라는 주관적 요청을 정밀한 명세로 바꾸는 도구이지, 다른 사이트의 저작물을 그대로 복제하라는 뜻은 아닙니다. 참고한 디자인의 저작권·브랜드 요소는 따로 신경 써야 합니다.
