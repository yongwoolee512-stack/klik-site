Ars Contexta

대화로 내 일하는 방식을 물어본 뒤, 나에게 맞는 노트 폴더·템플릿·자동 정리 규칙을 통째로 만들어 줍니다.

깃허브 원문 설명 한글판

이게 뭐예요?

'에이전트의 두 번째 뇌'. 대화로 내 분야와 일하는 방식을 설명하면 폴더 구조, 컨텍스트 파일, 처리 파이프라인, 훅, 길찾기 지도, 노트 템플릿을 통째로 만들어 주는 Claude Code 플러그인입니다. 템플릿이 아니라 249개 연구 근거에서 도출한다고 설명합니다. MIT.

받는 것

위키 링크로 이어진 마크다운 노트 저장소(데이터베이스·클라우드 없음), 인사이트 추출·연결·검증 스킬, 매번 쓸 때 구조를 지키는 훅과 자동 커밋, 허브·분야·주제별 목차(MOC), 노트 템플릿, 7쪽짜리 사용 설명서.

설치와 사용

플러그인 설치 → Claude Code 재시작 → /arscontexta:setup → 2~4개 질문에 답(약 20분, 토큰을 많이 씀, 한 번만) → 생성 뒤 다시 재시작 → /arscontexta:help.

구조

self/(에이전트의 정체성·방법·목표), notes/(지식 그래프), ops/(작업 큐·세션 상태) 세 공간으로 나뉘며 폴더 이름은 내 분야에 맞게 바뀝니다.
