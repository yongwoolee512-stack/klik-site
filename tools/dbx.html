깃허브 원문 설명 한글판

이게 뭐예요?

100종 이상의 데이터베이스를 25MB짜리 단일 실행 파일로 다루는 DB 도구입니다. Java도 Python도 내장 브라우저도 없이 내려받아 바로 연결합니다. MySQL·PostgreSQL·SQLite·Redis·MongoDB·DuckDB·ClickHouse 등은 물론 Kafka·RabbitMQ 같은 메시지 큐도 같은 화면에서 봅니다. 데스크톱(macOS·Windows·Linux), Docker, 웹, CLI, 내장 AI 비서, MCP 서버까지 제공합니다.

MCP 연결

DBX에 설정해 둔 연결을 AI 코딩 에이전트가 쓰게 하는 별도 Rust 기반 MCP 서버가 있습니다. `npx @dbx-app/mcp-server`로 띄우거나 .mcp.json에 `{"command":"npx","args":["-y","@dbx-app/mcp-server"]}`를 넣습니다. 연결 목록 조회, 테이블 탐색, SQL 실행, DBX 화면에서 표 열기를 지원합니다.

권한 관리

DBX 설정 → MCP에서 연결 허용 목록과 접근 모드(읽기 전용 / 데이터 읽기·쓰기 / 전체 접근)를 관리합니다. Windows 포터블 빌드는 MCP 설정에 DBX_DATA_DIR(DBX.exe 옆 data 폴더)을 지정해야 하고, 웹·Docker 배포는 DBX_WEB_URL과 비밀번호를 환경 변수로 넘깁니다.

라이선스

Apache 2.0, 무료 오픈소스입니다. 내장 AI 비서는 Claude·OpenAI·Ollama 로컬 모델과 연결되고, AI가 만든 SQL은 실행 전 안전 검사를 거칩니다.
