깃허브 원문 설명 한글판

이게 뭔가요?

자연어와 실제 시스템 소스를 유지보수 가능한 .drawio 구조도로 바꾸는 스킬입니다. 그리고 내보내는 데서 끝나지 않고 수동 배치를 지키며 점진적으로 동기화하고, 하나의 모델에서 여러 뷰를 뽑고, 아키텍처 규칙을 검사하고, 의존성을 질의하고, 장애 전파를 시뮬레이션하고, 의존성 없는 인터랙티브 설명 페이지를 발행합니다. Claude Code, Cursor, Copilot, Codex 등 Agent Skills 호환 도구에서 동작하며 영어·중국어 문서와 온라인 문서 사이트가 있습니다.

무엇을 할 수 있나요?

말로 설명하면 편집 가능한 .drawio를 만들고 PNG를 스스로 확인해 겹침·잘린 글자·겹친 선을 최대 2회 자동 수정(내 피드백은 5회까지). Mermaid 텍스트 28종(마인드맵, 간트, 타임라인, 파이, 칸반 등)을 배치된 .drawio로 변환(draw.io 30 이상). 화이트보드 사진·스크린샷을 편집 가능한 도면으로 복원. ERD, UML 클래스, 시퀀스, C4, 아키텍처, ML, 플로차트, SysML, BPMN, 네트워크, 스윔레인 11종 프리셋. 코드베이스(Python/JS·TS/Go/Rust), Terraform·Kubernetes·docker-compose, SQL DDL에서도 도면을 만듭니다.

쓰는 법

1) draw.io 데스크톱을 설치합니다(Windows는 설치 파일 다운로드, macOS는 brew install --cask drawio). drawio --version 으로 확인하고 30 이상을 권장합니다. 2) npx skills add Agents365-ai/drawio-skill -g 로 스킬을 설치합니다. 수동 설치 시 저장소 루트가 아니라 skills/drawio-skill/ 하위 폴더를 ~/.claude/skills/drawio-skill 로 링크하거나 복사해야 합니다.

주의할 점

WSL2에서는 윈도우용 drawio 실행 파일을 /mnt/c 경로로 쓰는데 스킬이 자동 감지한다고 합니다. 리눅스 헤드리스에서는 xvfb가 필요합니다. 저장소 루트를 스킬 폴더에 그대로 넣지 말라고 명시합니다.
