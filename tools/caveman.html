원문 설명 한글판

왜 많은 토큰, 적은 토큰도 되는데

원시인(Caveman)은 AI 에이전트가 '덜 말하고 덜 읽게' 합니다. 코드는 정확히 그대로. 머리는 여전히 큽니다.

같은 React 리렌더링 질문에 보통 에이전트는 63토큰("...이유는 아마 렌더마다 새 객체 참조를 만들어서인데, 인라인 객체를 prop으로 넘기면 React의 얕은 비교가..."), 원시인 에이전트는 20토큰("렌더마다 새 객체 참조, 그래서 React 재렌더. prop을 useMemo로 감싸."). 같은 해결책입니다.

증명

Adobe 연구(CAVEWOMAN 논문, 이 저장소 인용): 8개 모델·5개 데이터셋에서 비용 1.4~2.4배, 최대 3배 절감. JetBrains: 실제 코딩 과제 86개 A/B 테스트, 품질 저하 없음(p=0.82). Elastic: Elasticsearch용으로 재제작, 응답 토큰 63.6% 감소, '정보 손실 0'. 해커뉴스 1위, 깃허브 트렌딩 1위.

두 발견이 설계를 바꿨습니다. Adobe: '내 질문'을 원시인화하면 답이 나빠진다 → 원시인은 사용자 프롬프트를 절대 건드리지 않습니다. JetBrains: 에이전트 세션은 대부분 코드와 도구 호출 → 말투는 그걸 그대로 두고, 대신 에이전트가 '읽는 것'을 줄이는 기능이 생겼습니다.

여섯 개의 돌(4.0 기준)

덜 말하기: 답이 짧아짐, 코드는 정확(63→20토큰). 덜 읽기: 로그·JSON·CSV·테스트 출력을 모델이 읽기 전에 줄임(세션당 입력 토큰 33.2% 감소). 자동(Auto): 질문마다 모델과 노력 수준을 골라 줌(Opus 최고 설정 대비 54% 저렴, 같은 점수). 블록: 에이전트가 쓴 스크립트를 보관해 다시 씀(테스트 1회 397→76토큰). 낭비 수정, 그리고 원시인 클라우드.

전체 기능은 npx @caveman-ai/cli@latest 로 설치합니다(Node.js 22.13 이상). Claude Code 플러그인판(/plugin marketplace add JuliusBrussee/caveman → /plugin install caveman@caveman)은 매 대화 세션에 자동 시작되며, 딸깍은 이 플러그인판을 설치합니다.

원시인 말투의 규칙

망가진 문법이 아니라 '목소리'입니다. 답 먼저: [대상][동작][이유]. [다음 단계]. 인사·요약 없음. 한 문장에 한 생각(항공 정비 매뉴얼의 통제 영어 ASD-STE100 기반, 최대 20단어). 뜻은 절대 빠지지 않음: 관사는 빼도 not·never·no·only 는 안 뺌, 숫자와 단위는 정확. 코드·명령·경로·오류 메시지는 글자 하나 안 건드림. 보안 경고·되돌릴 수 없는 작업·헷갈리는 사용자에게는 완전한 문장으로 돌아옴. 내 프롬프트는 절대 다시 쓰지 않음.

/caveman 보통, /ultracave 더 짧게, /megacave 한자 압축. 'stop caveman' 으로 돌아옵니다. 솔직한 숫자: 'Be concise' 한 줄만 써도 꽤 줄어들고, 그 위에 /caveman은 3%, /ultracave는 35% 더 줄입니다. 요청당 과금(Copilot)에서는 짧은 답이 돈을 아끼지 않습니다.
