이런 분께

슬라이드·화면 시안·데이터 대시보드를 Claude Code에서 만들고 편집기로 다듬고 싶은 분. Node.js 20 이상(대시보드는 22 이상)이 필요합니다

사용 예시

  • "/claude-slides 이 기획서로 10장짜리 발표 자료 만들어 줘"
  • "이 CSV로 필터 가능한 대시보드 만들어 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

claude.ai의 아티팩트 유형(편집 가능한 슬라이드 덱, 디자인 캔버스, 디자인 시스템, 데이터 대시보드)을 Cursor, Claude Code, Claude Desktop 같은 로컬 에이전트에서 쓰게 해 주는 저장소입니다. 각 결과물은 내 컴퓨터에서 돌아가는 전용 편집기로 열립니다. 웹사이트도, 별도 구독도, 업로드도 없고 모든 결과물은 내 저장소에 남습니다. 예전의 baoyu-design 스킬(단일 HTML 목업)은 archive/로 옮겨졌습니다.

안에 뭐가 있나요?

claude-slides(project/deck.json과 슬라이드별 HTML, 편집기에서 발표·글 수정·드래그, PDF/HTML/PowerPoint 내보내기), claude-design(아트보드 캔버스와 디자인 컴포넌트, 프로토타입 재생, HTML/PDF/PNG 내보내기), claude-design-system(토큰, 브랜드북 README, 컴포넌트 미리보기, 폰트, 에셋), claude-dashboard(CSV/TSV/JSON 데이터셋 위의 차트·숫자·표, 모든 숫자를 원본 행까지 추적하는 Sources 패널), dataviz(어떤 매체에서든 차트를 그리기 전에 읽는 가이드: 형태 선택, 라이트/다크·색각 이상에서 읽히는 색). 네 편집기는 DeepSeek Harness 플러그인으로도 npm에서 설치할 수 있습니다.

쓰는 법

준비물은 로컬 에이전트(Claude Code 등), 최상의 결과를 위한 Claude Opus 5.5 모델, Node.js(편집기용 20 이상, 대시보드는 22 이상). npx skills add JimLiu/baoyu-design (전역 -g, 특정 스킬만 --skill claude-slides). Claude Code는 .claude/skills/에 설치됩니다. 업데이트는 npx skills update claude-slides.

주의할 점

같은 저장소 안에 작업 공간 자체 복사본(.agents/skills/ 등)이 있으면 플러그인 대신 그 복사본을 씁니다. 딸깍에 이미 있는 baoyu-skills(JimLiu/baoyu-skills)와는 다른 저장소입니다.
