하지 말 것 규칙 만들기 (Hookify)

Hookify

"이건 하지 마"를 말로 하면 Claude가 그 행동을 못 하게 막는 규칙을 만들어 줍니다.

GitHub ★ 45,473
딸깍에서 한 번에 설치하기

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

Claude가 자꾸 같은 실수(파일 지우기, 엉뚱한 명령)를 반복하는 분

사용 예시

  • "/hookify 앞으로 .env 파일은 절대 건드리지 마"
  • 대화를 분석해서 반복되는 나쁜 패턴을 찾아 규칙으로 만들어 주기도 합니다.

깃허브 원문 설명 한글판

이게 뭐예요?

Claude Code의 훅(hook: 특정 동작 전에 자동으로 끼어드는 규칙)을 말로 만들어 주는 Anthropic 공식 플러그인입니다. "이 파일은 건드리지 마", "이 명령은 실행 전에 물어봐" 같은 규칙을 대신 써 줍니다. 대화를 분석해 반복되는 나쁜 패턴을 찾아 규칙으로 제안하기도 합니다.

설치와 첫 사용

딸깍 설치 뒤 "/hookify 앞으로 .env 파일은 절대 건드리지 마"처럼 말하면 규칙이 생깁니다.
