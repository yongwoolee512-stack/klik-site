Repomix

프로젝트 전체 코드를 AI가 읽기 좋은 한 파일로 묶어 주고, 비밀번호 같은 민감 정보를 걸러 줍니다.

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

개발자. 코드베이스를 다른 AI에 통째로 보여 주고 싶을 때

사용 예시

  • "이 저장소를 repomix로 묶어서 요약해 줘"

깃허브 원문 설명 한글판

이게 뭐예요?

저장소 전체를 AI가 읽기 좋은 파일 하나로 묶어 주는 도구입니다. Claude, ChatGPT, Gemini 등에 코드베이스를 통째로 넘길 때 씁니다. JSNation 오픈소스 어워드 후보에 올랐습니다.

주요 기능

AI 최적화 포맷, 파일별·전체 토큰 수 계산, 한 명령 사용, Secretlint로 API 키·비밀번호 등 민감 정보 검사. repomix.com 에서 브라우저로도 쓸 수 있습니다.

Claude Code 플러그인

repomix-mcp(MCP 서버, 기본 권장), repomix-commands(슬래시 명령), repomix-explorer(AI 분석) 세 가지. 셋 다 설치하면 가장 완전합니다.

주의

--sandbox 없이 실행하면 묶는 폴더의 repomix.config 를 그대로 신뢰합니다. 결과 파일에 민감 정보가 남지 않았는지 공유 전 확인하세요.
