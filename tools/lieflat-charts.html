Lieflat Charts

CSV·표 데이터를 주면 편집 디자인 느낌의 HTML 차트를 만들어 줍니다. 꼼꼼히 읽는 '루피', 10초에 파악하는 '글랜스', 익숙한 기본형 세 가지 스타일과 흑백·청자색·녹색·빨강 색 세트가 있습니다.

이런 분께

보고서·블로그·발표에 넣을 차트가 엑셀 기본형보다 예쁘길 바라는 분. 요청하면 차트 PPT(HTML)나 한 장짜리 리포트도 만듭니다

사용 예시

  • "이 주간 매출 CSV를 Glance 스타일 차트로 만들어 줘, 10초 안에 순위랑 변화가 보이게"
  • "이 설문 결과를 블로그용 한국어 차트 4장으로 만들어 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

Agent Skills 형식의 데이터 시각화·차트 PPT·한 장 리포트 생성 스킬입니다. moxt.ai에서 만들었고 Claude Code, Codex 등 SKILL.md 호환 에이전트에서 씁니다. 기본 결과물은 차트이고, PPT·슬라이드를 명확히 요청할 때만 HTML/PDF 발표 모드, 보고서·연보·백서·포스터를 요청할 때만 전체 HTML 리포트를 만듭니다. 영어 README(README.en.md)가 있습니다.

세 가지 스타일과 색

Lupi(편집 서사형): 가는 선, 점, 기록 하나하나, 넉넉한 여백으로 논문·장문·연보용. Glance(빠른 판단형): 굵은 막대, 큰 숫자, 색 블록으로 몇 초 안에 높낮이·변화·이상치를 읽는 주간 보고·대시보드용. Basics(기본 편집형): 막대·꺾은선·도넛 등 익숙한 형태에 가는 눈금과 편집 타이포를 더한 것. 네트워크·경로·흐름용 인터랙티브 대형 차트도 있습니다. 색은 흑백 Mono가 기본이고 청자색(Porcelain), 야자녹(Palm), 편집부 빨강(Wire) 세 세트에서 데이터 구조에 따라 자동 선택하며 브랜드색으로 커스텀 팔레트도 만듭니다. 템플릿은 Lupi Editorial 15, Basics 13, Glance 18, Interactive 3.

쓰는 법

npx skills add https://github.com/larashero3-dotcom/lieflat-charts --skill lieflat-charts 로 설치하거나 에이전트에 '~/.claude/skills/lieflat-charts 에 클론하고 SKILL.md, templates/, catalog.md, mono-tokens.js 가 있는지 확인해 줘'라고 부탁합니다. 이후 '이 조사 데이터를 블로그 장문용 차트 5장으로', '이 CSV를 보고서용 Glance 차트 한 장으로', '청자색 프리셋으로 명도 차이로 값을 표현해 다시' 같은 요청을 합니다.

차트 수 규칙

차트 수는 독립된 결론 수로 정합니다. 질문 하나면 보통 1장, 결론 2~3개면 2~3장, 글·논문 전체면 4~6장, 한 페이지 최대 6장. 수를 지정하면 따르지만 같은 결론을 억지로 반복하지는 않습니다. 발표 모드는 16:9 단일 HTML로 화살표 넘기기·개요·인쇄를 지원하고 색 세트별 중국어·영어 19쪽 템플릿이 있습니다.
