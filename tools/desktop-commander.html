이게 뭐예요?

Desktop Commander는 깃허브에서 인기 많은 MCP 서버입니다. 터미널 명령, 프로그램 관리, 파일 작업(텍스트·코드·PDF·워드·엑셀·이미지)을 Claude가 내 컴퓨터에서 직접 합니다.

설치와 첫 사용

딸깍 설치 뒤 "다운로드 폴더 종류별로 정리해 줘"처럼 씁니다.

주의

내 컴퓨터 파일을 실제로 옮기고 지웁니다. 삭제 작업은 "지우기 전에 목록 보여 줘"라고 하세요.
