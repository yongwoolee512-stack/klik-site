이런 분께

Remotion으로 영상을 만드는 개발자. React와 Node.js 환경이 있어야 하는 개발자용 도구입니다

사용 예시

  • "/remotion-create 레코드 가게 홍보 영상 만들어 줘"
  • "/remotion-render 로 지금 영상 MP4로 뽑아 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

React 코드로 영상을 만드는 도구 Remotion의 공식 에이전트 스킬입니다. Remotion 프로젝트에서 지켜야 할 모범 사례를 정리해 Claude Code, Codex, Cursor 등이 올바른 코드를 쓰게 합니다. 새 Remotion 프로젝트를 만들 때(bun create video) 함께 설치할지 묻기도 합니다.

안에 뭐가 있나요?

remotion-best-practices(전체를 아우르는 기본 스킬, 뭘 쓸지 모르면 이것), remotion-create(새 프로젝트·컴포지션 만들기), remotion-markup(애니메이션·레이아웃·글꼴·오디오 작성 규칙), remotion-studio(미리보기 실행), remotion-render(영상·스틸 렌더링), remotion-maps(지도 애니메이션), remotion-captions(자막), remotion-saas(앱에 영상 기능 넣는 설계), remotion-interactivity, remotion-docs(문서 검색), remotion-upgrade(버전 업), remotion-multimedia(영상·오디오 메타데이터).

쓰는 법

/remotion-create 레코드 가게 홍보 영상 만들어 줘, /remotion-render, /remotion-docs Remotion Lambda 설정 방법? 처럼 슬래시 명령 뒤에 요청을 붙입니다.

주의할 점

React와 Node.js를 다룰 줄 아는 개발자를 위한 도구입니다. 코드 없이 영상을 만들고 싶다면 같은 범주의 하이퍼프레임(HyperFrames)이 더 가깝습니다.
