깃허브 원문 설명 한글판

없으면 어떻게 되나 (원문 Without Context7)

AI는 1년 전 학습 자료에 의존해 옛날 코드 예시를 주고, 존재하지도 않는 기능을 지어내고, 옛 버전 기준으로 답합니다.

있으면 (원문 With Context7)

Context7은 쓰고 있는 라이브러리의 최신·해당 버전 공식 문서와 코드 예시를 원본에서 바로 가져와 AI에게 넘겨 줍니다. 탭 왔다 갔다 할 필요도, 지어낸 기능에 속을 일도 없습니다.

두 가지 방식

• CLI+스킬: ctx7 명령으로 문서를 가져오게 하는 스킬 (MCP 불필요)
• MCP: Context7 MCP 서버를 등록해 AI가 문서 도구를 직접 호출 — 딸깍은 이 방식의 원격 서버(mcp.context7.com)를 등록합니다.

API 키 (권장)

context7.com/dashboard 에서 무료 키를 받으면 사용 한도가 올라갑니다. 없어도 동작합니다.
