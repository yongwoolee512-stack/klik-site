이게 뭐예요?

서비스·애플리케이션·도구 아이콘과 로고 3,400개 이상을 모은 컬렉션입니다. 대시보드와 앱 디렉터리용으로 다듬어졌고 SVG·PNG·WEBP, 라이트·다크 변형을 무료 CDN으로 제공합니다. dashboardicons.com 에서 찾아볼 수 있습니다.

MCP 서버로 쓰면

docker-compose.yml 이나 대시보드 설정의 서비스마다 아이콘을 한 번에 매칭하고, CDN 링크나 원본 SVG를 돌려 주며, selfh.st·LobeHub·Simple Icons 카탈로그도 라이선스와 함께 검색합니다. 로그인하면 빠진 아이콘 제출도 대신해 줍니다.

설치

서버는 무료이고 API 키가 없습니다. 주소는 https://dashboardicons.com/api/mcp, Claude Code·Codex·ChatGPT·Cursor·VS Code 모두 지원.
