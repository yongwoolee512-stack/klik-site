skills.sh 원문 설명 한글판

이게 뭔가요?

Vercel Labs가 공개한 AI 코딩 도우미용 스킬 모음입니다. Vercel 엔지니어링 팀이 실제로 쓰는 성능·디자인·글쓰기 기준을 Claude가 코드를 쓰거나 검토할 때 따르도록 합니다.

안에 뭐가 있나요?

react-best-practices(React/Next.js 성능 규칙 40여 개, 영향도 순), web-design-guidelines(접근성·포커스·폼·애니메이션·타이포·다크모드 등 100여 개 규칙으로 UI 코드 점검), writing-guidelines(문서 문체 규칙 80여 개), react-native-guidelines, react-view-transitions(페이지 전환 애니메이션), composition-patterns(컴포넌트 설계), vercel-optimize(배포된 프로젝트의 비용·성능 진단), deploy-to-vercel(배포: git push 우선, 로그인 없으면 임시 배포 링크).

쓰는 법

설치하면 관련 작업을 감지해 자동으로 쓰입니다. "내 앱 배포해 줘", "이 React 컴포넌트 성능 문제 검토해 줘", "이 Next.js 페이지 최적화 도와 줘" 같은 말로 부릅니다.

주의할 점

대부분 React/Next.js 코드가 있는 프로젝트를 전제로 합니다. 비개발자에게는 web-design-guidelines 정도가 '내 사이트 점검' 용도로 쓸 만합니다.
