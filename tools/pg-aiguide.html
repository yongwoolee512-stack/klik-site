PostgreSQL 가이드 (pg-aiguide)

pg-aiguide

Claude가 PostgreSQL 코드를 짤 때 제약조건·인덱스·최신 기능을 빠뜨리지 않도록 Timescale이 정리한 모범 사례 스킬(postgres, schema-exploration)입니다.

설치 명령을 복사·실행하는 과정을 딸깍 홈에서 안내합니다.

이런 분께

개발자용. Postgres 데이터베이스 설계·조회를 Claude에 맡기는 분. 공식 문서 검색이 필요하면 공개 MCP 서버(mcp.tigerdata.com)도 함께 쓸 수 있습니다

사용 예시

  • "쇼핑몰용 Postgres 스키마를 pg-aiguide 기준으로 설계해 줘"
  • "schema-exploration으로 지금 연결된 DB 구조 파악해서 설명해 줘"

깃허브 원문 설명 한글판

이게 뭔가요?

AI 코딩 도구가 훨씬 나은 PostgreSQL 코드를 쓰게 돕는 TimescaleDB 개발사의 프로젝트입니다. 공식 PostgreSQL 매뉴얼의 버전별 의미 검색, AI 에이전트가 자동으로 쓰는 엄선된 Postgres 모범 사례 '스킬', TimescaleDB부터 시작하는 확장 문서를 제공합니다. npx skills 로 설치하는 Agent Skills, 공개 MCP 서버, Claude Code 플러그인 세 형태로 쓸 수 있습니다.

왜 필요한가요?

AI가 만드는 Postgres 코드는 종종 오래됐고, 제약조건·인덱스가 빠지고, 최신 PG 기능을 모르고, 실무 모범 사례와 어긋납니다. README의 비교 실험(전자상거래 스키마를 켜고/꺼서 두 번 생성)에서는 제약조건 4배, 인덱스 55% 증가(부분·표현식 인덱스 포함), PG17 권장 패턴, GENERATED ALWAYS AS IDENTITY·NULLS NOT DISTINCT 같은 최신 기능, 더 깔끔한 이름과 문서화가 나왔다고 합니다.

쓰는 법

npx skills add timescale/pg-aiguide --skill postgres (모범 사례), --skill schema-exploration (기존 DB 구조 탐색), 또는 인수 없이 실행해 대화형으로 고릅니다. 더 깊은 문서 검색은 공개 MCP 서버 https://mcp.tigerdata.com/docs 를 MCP 설정에 추가하거나 claude plugin marketplace add timescale/pg-aiguide 후 claude plugin install pg@aiguide 로 플러그인을 설치합니다. Cursor·VS Code용 원클릭 설치 링크도 있습니다.

주의할 점

Postgres로 개발하는 사람용입니다. MCP 서버는 Tiger Data가 운영하는 공개 서버로 질의가 외부로 나갑니다.
