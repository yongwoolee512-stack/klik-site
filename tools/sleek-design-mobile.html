이런 분께

앱 아이디어는 있는데 디자이너가 없는 사람. Sleek 계정과 API 키가 필요하고, 무료는 체험 1회 정도라 계속 쓰려면 유료(월 69달러)입니다

사용 예시

  • "가계부 앱의 홈 화면과 지출 입력 화면 디자인해 줘"
  • "방금 만든 화면을 다크 모드 버전으로도 만들어 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

Sleek(sleek.design)이라는 AI 모바일 앱 디자인 서비스의 공식 에이전트 스킬입니다. design-mobile-apps 스킬 하나로 모바일 앱을 디자인하고, 화면을 만들고, Sleek 프로젝트를 관리할 수 있습니다.

준비물

Sleek 계정이 필요합니다. 무료 계정은 일회성 체험 크레딧(디자인 한 번 정도)만 제공되고, 계속 쓰려면 Pro 요금제 이상(월 69달러, 연간 결제 시 월 30달러)이 필요합니다. API 키를 만들어 SLEEK_API_KEY 환경변수에 넣어야 합니다.

주의할 점

npx skills add로 설치하면 작업 폴더의 .agents/skills/에 들어가는데, 도우미가 그 위치를 못 찾으면 SKILL.md 경로를 직접 알려 줘야 할 수 있습니다. 딸깍 도우미는 ~/.claude/skills에 복사하므로 그 문제는 피할 수 있습니다.
