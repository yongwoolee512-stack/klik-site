이게 뭐예요?

클라우드플레어는 MCP 서버를 여러 개 제공합니다. AI가 내 클라우드플레어 계정의 설정을 읽고, 분석하고, 제안하고, 허락하면 실제로 바꿔 주기까지 합니다. 도메인·DNS·보안·서버리스(Workers)까지 범위가 넓습니다.

서버 종류 (원문 표)

• 클라우드플레어 API 서버(권장): 전체 기능 — mcp.cloudflare.com/mcp
• 문서 서버: 최신 참고 문서 검색 — docs.mcp.cloudflare.com/mcp
• 컨테이너 서버: 샌드박스 개발 환경
• 브라우저 서버: 웹페이지 가져와 마크다운 변환·스크린샷
• 그 외 보안(CASB), 모니터링(DEX), 블로그 서버 등

주의 (원문)

예전 /sse 주소는 폐기돼 '410 Gone' 오류를 냅니다. 반드시 /mcp 로 끝나는 주소를 써야 합니다. 딸깍은 권장 서버인 mcp.cloudflare.com/mcp 를 등록합니다. 처음 쓸 때 클라우드플레어 로그인 창이 뜹니다.
