깃허브 원문 설명 한글판

이게 뭔가요?

AI 코딩 에이전트용 게임 개발 스킬 77개와, 무엇을 만들고 있는지 보고 맞는 스킬을 불러오는 라우터를 한 번에 설치하는 저장소입니다. Godot, Unity, Unreal, Ebitengine, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE, Defold, Roblox을 다룹니다. 모든 스킬이 1차 공식 문서를 바탕으로 쓰였고 엔진 버전을 명시하며(예: Godot 4.7) 검증 스크립트로 점검됩니다.

라우터가 하는 일

스킬 이름을 외울 필요가 없습니다. 요청마다 라우터가 1) 프로젝트 파일로 엔진을 감지(project.godot이면 Godot, *.uproject면 Unreal, 모르면 물어봄), 2) 요청에서 과제(AI·셰이더·저장), 장르(플랫포머·로그라이크), 출시 단계(게임잼·Steam)를 읽고, 3) 엔진 기본→개념→장르 순으로 맞는 스킬만 로드합니다. 예: 'Godot 플레이어에 더블 점프'는 godot-2d-movement + platformer, 'Unity RPG 인벤토리'는 unity-scriptableobjects + rpg + save-systems.

안에 뭐가 있나요?

9개 카테고리 77개. 엔진별(Godot 16개: GDScript, 노드·씬, 시그널, 2D 이동, 타일맵, 물리, UI, 애니메이션, 셰이더, 3D, 리소스, 오디오, 멀티플레이어 등), 분야별(AI 행동 트리, 오디오 디자인, 카메라, 대화 시스템, 게임 에셋 제작 등), 장르, 출시(itch-publish 등). 에셋 제작 스킬은 시각 목표를 고정하고 가족 단위로 만들어 게임 안에서 확인합니다.

쓰는 법과 주의

npx skills add gamedev-skills/awesome-gamedev-agent-skills (Node.js 22.20 이상), --list 로 미리 보기, -g 로 전역 설치. Claude 플러그인 마켓(claude plugin marketplace add … / claude plugin install gamedev@…)으로도 됩니다. 스킬 77개가 설치되므로 게임 개발을 하지 않는 분은 받지 않는 게 좋습니다. 개발자용입니다.
