이게 뭐예요?

플레이라이트 MCP는 AI가 브라우저를 직접 열어 페이지를 읽고, 클릭하고, 입력하게 해 주는 도구입니다. 화면을 사진으로 보는 게 아니라 페이지의 구조(접근성 트리)를 읽어서 빠르고 정확합니다.

특징

• 빠르고 가벼움: 픽셀이 아니라 구조 데이터로 동작
• 별도 시각 모델 불필요
• 결과가 일정함: 스크린샷 방식의 모호함이 없음

MCP 대 CLI (원문 안내)

마이크로소프트는 코딩 에이전트에는 MCP보다 CLI+스킬 방식(playwright-cli)이 토큰을 덜 써서 낫다고 안내합니다. MCP는 브라우저 상태를 오래 유지해야 하는 자동화(탐색형 테스트, 장시간 작업)에 알맞습니다.

필요한 것

Node.js 18 이상이 컴퓨터에 있어야 합니다. 딸깍 설치는 npx로 실행하는 방식이라 Node가 없으면 설치 뒤 실행이 안 됩니다. (딸깍 편집팀 주: Node 없는 분은 설치 전에 nodejs.org에서 받으세요.)
