이게 뭔가요?

Firecrawl의 공식 명령줄 도구입니다. 웹 검색, 페이지 긁어오기(scrape), 파싱, 사이트 전체 수집(crawl), 사이트 구조 파악(map), 페이지와 상호작용(interact), 연구 논문·개발자 자료·정부 자료 검색, 에이전트 작업 실행을 터미널에서 바로 할 수 있습니다.

안에 뭐가 있나요?

스킬은 세 가족으로 나뉩니다. core는 검색·수집·상호작용 같은 기본 명령 스킬, build는 Firecrawl API를 앱에 붙이는 스킬, workflows는 리서치 브리프·SEO 감사·QA 보고서·리드 목록·지식 베이스·디자인 시스템 추출 같은 완성형 결과물을 만드는 레시피입니다. firecrawl setup core / build / workflows로 가족별로 설치합니다.

쓰는 법

npm install -g firecrawl-cli로 설치하거나, npx -y firecrawl-cli@latest init -y --browser 한 줄로 설치·로그인·스킬 설치를 한 번에 끝낼 수 있습니다. 첫 실행 때 브라우저 로그인 또는 API 키 입력으로 인증하며, FIRECRAWL_API_KEY 환경변수로도 넘길 수 있습니다. Claude Code·Codex·Cursor·Windsurf 등 감지된 에이전트에 스킬이 자동 연결됩니다.

주의할 점

Firecrawl 계정과 API 키가 필요합니다(무료 등급이 있으며, 자체 호스팅 인스턴스는 --api-url로 키 없이 사용 가능). 기존 '파이어크롤' 플러그인(공식 마켓플레이스)과는 별도 배포라 이 CLI 스킬이 거기엔 들어 있지 않습니다. 설치된 스킬이 최신 카탈로그와 다르면 알림이 뜨며, FIRECRAWL_NO_UPDATE_CHECK=1로 끌 수 있습니다.
