깃허브 원문 설명 한글판

이게 뭐예요?

AI 코딩 도구 청구서는 월 총액만 알려 주지, 어느 프로젝트·어느 모델·어떤 작업에 얼마가 들었고 어디가 낭비였는지는 안 보여 줍니다. Claude Code, Codex, Cursor 등은 쓸 때마다 토큰과 모델 호출이 담긴 세션 파일을 남기는데, CodeBurn은 그 파일을 읽어 내역을 만들어 줍니다. 계정도 가입도 없습니다.

60초 사용법

`npx codeburn` 한 줄이면 터미널에 오늘 쓴 돈과 도구별·모델별·프로젝트별·작업별 표가 뜹니다. 화살표로 기간을 바꾸고 p로 도구를 전환합니다. 같은 숫자를 데스크톱 앱, macOS 메뉴 막대, 화면 가장자리의 Capacity Dock, `codeburn web` 브라우저 화면에서도 볼 수 있습니다. Windows 데스크톱 앱은 Microsoft Store에 있습니다.

낭비 잡기

`codeburn optimize`는 매 턴마다 다시 읽히는 파일, 깔아 놓고 안 쓰는 MCP 서버, 너무 길어진 CLAUDE.md처럼 토큰만 먹는 것을 등급·수정 방법·예상 절감액과 함께 알려 줍니다. `--apply`로 고쳐 주고 `codeburn act undo --last`로 되돌립니다. `codeburn plan set`과 `codeburn quota`로 내 구독 한도 소진 상황을, `codeburn guard install`로 세션당 지출 상한 훅을 둘 수 있습니다.

Claude Code 안에서

`/plugin install codeburn --marketplace getagentseal/codeburn`으로 플러그인을 깔면 MCP 서버와 `/codeburn:cost` 명령이 생깁니다. MCP만 등록하려면 `claude mcp add codeburn -- npx -y codeburn mcp`. 이 서버는 디스크의 파일만 읽고 네트워크 요청을 하지 않으며, 프로젝트 이름은 요청하지 않으면 익명화됩니다. 도구는 get_usage(지출 내역)와 get_savings(낭비 분석) 두 개입니다.

비용과 라이선스

MIT 라이선스로 CLI, 데스크톱 앱, 메뉴 막대 앱 전부가 저장소에 있고 유료 등급이나 숨겨진 기능은 없습니다. 데스크톱 앱과 Windows 트레이는 동의한 경우에만 익명 사용 보고를 보낼 수 있습니다. Node.js 22.13 이상이 필요합니다.
