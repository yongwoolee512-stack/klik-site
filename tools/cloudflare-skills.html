이게 뭔가요?

Cloudflare가 공식으로 만든 에이전트 스킬 모음으로, Workers·Agents SDK 등 Cloudflare 개발 플랫폼에서 무언가를 만들 때 AI가 정확한 최신 가이드를 따르게 합니다. 대화 내용이 스킬의 조건과 맞으면 자동으로 로드됩니다.

안에 뭐가 있나요?

어떤 Cloudflare 제품이 맞는지 안내하는 cloudflare 스킬을 시작으로, Workers 배포·관리(wrangler), 운영용 Workers 작성 모범 사례, 상태를 가진 AI 에이전트(agents-sdk), 채팅방·게임 같은 상태 조정(durable-objects), 샌드박스, Next.js 배포, 이메일 서비스, Turnstile 봇 검증, Core Web Vitals 점검(web-perf), Cloudflare One 설계·마이그레이션 등이 표로 정리되어 있습니다.

쓰는 법

Claude Code에서는 /plugin marketplace add cloudflare/skills 뒤 /plugin install cloudflare@cloudflare로 설치하며, 이때 Cloudflare MCP 서버도 함께 들어옵니다. Codex·VS Code·Cursor용 설치법과 npx skills add, 저장소 복제 후 스킬 폴더 복사 방법도 안내합니다.

주의할 점

Cloudflare 플랫폼 개발이 전제인 개발자용 스킬입니다. Cloudflare 계정과 배포 대상 프로젝트가 있어야 의미가 있습니다.
