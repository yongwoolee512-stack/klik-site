이게 뭔가요?

Firebase가 공식으로 만든 AI 코딩 에이전트용 스킬 모음입니다. 에이전트가 Firebase를 더 잘 이해하고 다루도록 돕는 안내서와 스크립트를 Agent Skills 표준 형식으로 담았습니다. skills.sh 목록 기준으로 기본, 인증, 호스팅, App Hosting, Data Connect, 보안 규칙 감사, AI Logic, Firestore 스킬이 들어 있습니다.

쓰는 법

설치 방법이 여덟 가지나 소개됩니다. npx skills add firebase/skills(skills CLI), Gemini CLI 확장, Claude 플러그인(마켓플레이스 추가 후 firebase@firebase 설치), Codex 플러그인, Kimi 플러그인, 저장소를 직접 복제해 Cursor·Windsurf·Copilot 폴더에 복사, 로컬 경로 설치, 개발용 심볼릭 링크입니다.

주의할 점

README가 설치 절차 위주라 각 스킬이 무엇을 하는지는 저장소 안 SKILL.md를 봐야 합니다. Firebase 개발을 전제로 하는 개발자용 스킬이며, Apache 2 라이선스입니다.
