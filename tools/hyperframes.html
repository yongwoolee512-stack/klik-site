이런 분께

짧은 홍보·소개 영상, 자막 영상, 모션 그래픽을 편집 프로그램 없이 만들어 보고 싶은 사람. Node.js가 필요합니다

사용 예시

  • "/hyperframes 제목이 서서히 나타나고 배경 영상에 잔잔한 음악 깔린 10초 제품 소개 영상 만들어 줘"
  • "이 영상에 한국어 자막 넣어서 다시 렌더링해 줘"

skills.sh 원문 설명 한글판

이게 뭔가요?

HTML, CSS, 이미지·영상·음악 파일과 애니메이션을 재료로 결정적(매번 똑같이 나오는) MP4 영상을 만들어 내는 오픈소스 도구입니다. 'HTML을 쓰면 영상이 렌더링된다'가 한 줄 설명이고, AI 코딩 도우미와 함께 쓰도록 설계됐습니다. 맥·윈도우·리눅스용 데스크톱 앱도 있습니다.

안에 뭐가 있나요?

스킬 7개가 들어 있고 핵심은 4개입니다. hyperframes(영상 만들기의 규칙과 작업 순서를 담은 본체, 가장 먼저 읽힘), hyperframes-cli(새 프로젝트 만들기·검사·미리보기·렌더링·클라우드 렌더링 명령), hyperframes-registry(전환 효과, 자막, 제목, 차트, 지도, 3D 등 450여 개 완성 블록), media-use(이미지·영상·음악 다루기). 슬라이드쇼, Remotion 변환, Figma용 스킬은 필요할 때 추가합니다.

쓰는 법

Claude Code에서는 플러그인으로 설치하고 /hyperframes:hyperframes 를 부릅니다. 예시 프롬프트: "/hyperframes 로 페이드인 제목, 배경 영상, 잔잔한 배경음악이 있는 10초 제품 인트로 만들어 줘". 스킬이 영상 기획 → HTML 작성 → 애니메이션 연결 → 미디어 추가 → 검사 → 미리보기 → 렌더링 순서로 작업을 이끕니다.

주의할 점

영상 프로젝트 폴더 안에서 작업해야 하며, 자동 업데이트를 켜 두는 것을 권장합니다. skills.sh로 설치하면 등록 정보가 최신 코드보다 몇 시간 늦을 수 있어 npx hyperframes skills update 로 최신 스킬을 받는 방법도 안내합니다.
