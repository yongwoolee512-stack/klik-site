깃허브 원문 설명 한글판

이게 뭔가요?

어떤 지식 소스든 옵시디언 StudyVault(공부 보관소)로 바꾸고 그 내용으로 퀴즈를 내는 Claude Code 스킬 두 개입니다. 콘텐츠에서 이해까지 고리를 닫는 것이 목표입니다. tutor-setup(/tutor-setup)은 문서나 소스 코드로 노트·대시보드·연습 문제가 든 보관소를 만들고, tutor(/tutor)는 기존 보관소로 한 라운드 4문제씩 채점하며 개념별 진도를 추적하는 대화형 퀴즈를 진행합니다.

문서 모드

작업 폴더의 PDF, TXT, MD, HTML, EPUB를 자동 스캔해 소스 매핑을 검증하며 내용을 추출하고, 비교표·ASCII 다이어그램·시험 패턴이 든 개념 노트, 답이 숨겨진 연습 문제(접기 콜아웃으로 능동 회상, 주제당 8개 이상), MOC(콘텐츠 지도)·빠른 참조·시험 함정이 든 대시보드를 만들고 모든 노트를 [[위키링크]]로 연결합니다. D1 소스 발견부터 D9 자체 검토까지 9단계로 진행하고 00-Dashboard/, 01-주제/ 같은 번호 폴더 구조로 저장합니다.

코드베이스 모드

package.json, pom.xml, Cargo.toml, go.mod 같은 프로젝트 파일이 있으면 자동으로 코드베이스 모드가 되어 새 개발자 온보딩 보관소를 만듭니다. 기술 스택·아키텍처 패턴·모듈 경계를 감지하고 요청·데이터 흐름을 끝까지 추적하며 모듈별 핵심 파일·공개 인터페이스·의존성 지도를 적습니다.

쓰는 법과 주의

공부 자료 폴더에서 claude 를 열고 /tutor-setup, 그다음 /tutor. README의 한 줄 설치 명령과 수동 설치는 RoundTable02/tutor-skills 라는 옛 주소를 쓰는데 현재 저장소는 bevibing/tutor-skills 이므로(이전된 것으로 보임) 딸깍은 현재 주소로 설치합니다. 결과물을 보고 쓰려면 옵시디언 앱이 있어야 합니다.
