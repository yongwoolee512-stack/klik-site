깃허브 원문 설명 한글판

이게 뭐예요?

ECC(Everything Claude Code)는 에이전트에게 조율된 공학 작업 체계를 깔아 주는 묶음입니다. 만들기 전에 계획하고, 테스트로 검증하고, 새 컨텍스트에서 자기 작업을 검토하고, 중요한 것을 기억하고, 반복되는 성공을 재사용 스킬로 바꿉니다. 매 프롬프트에 이 과정을 다시 쓰는 대신 한 번 설치해 두는 것입니다. MIT 라이선스입니다.

들어 있는 것

에이전트 71개(계획·검토·빌드 복구·보안·아키텍처), 스킬 314개(TDD·리서치·보안·문서·프런트엔드·데이터·ML·운영), 명령 98개, 훅과 메모리(세션 요약·지속 학습·컨텍스트 제어), 선택형 규칙 팩, 그리고 프롬프트·훅·MCP 설정·권한·비밀을 스캔하는 AgentShield가 포함됩니다.

설치

권장은 `npx ecc-universal@2.2.3 setup` 안내형 설치(Node 18 이상, Git, Claude Code 2.1 이상 필요). Claude Code 안에서 `/plugin marketplace add https://github.com/affaan-m/ECC` → `/plugin install ecc@ecc`로도 같은 ecc@ecc 플러그인이 깔립니다. 둘 중 하나만 쓰고 수동 설치(install.sh)를 겹치지 마세요. 설치 뒤 `/ecc:configure-ecc`로 재설정합니다.

주의

README는 깃허브 저장소와 npm ecc-universal·ecc-agentshield 등 공식 채널에서만 설치하라고 경고합니다. Claude Code 플러그인은 rules를 배포할 수 없어 원하는 규칙 팩(rules/common + 쓰는 언어 하나)만 저장소에서 복사합니다. 진단은 자동 업로드되지 않습니다.
